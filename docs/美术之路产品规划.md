# 绘画星球（演示版）产品规划

> 版本：v2.0 · 2026-11-07（v1.0 首版演示同日完成，2.0 打磨内容见第 11 节）
> 工程：`D:\桌面\阅卷系统\art-road`（由「音乐之路」2.0 复制改造）
> 关联系统：艺考网阅卷系统（机构端 grading-web、扫描端 examScan、学情小程序、报名 H5）

## 1. 背景与目标

艺考网阅卷系统已经覆盖了「办考 → 扫描 → 评级评分 → 仲裁 → 查分 → 归档」的完整链路，但学生和老师在日常学习中缺少一个围绕这些数据展开的大屏学习工具。音乐之路已经验证过 iPad 横屏学习 App 的形态（左侧导航、顶栏、智慧校园五角色）。

绘画星球的目标：

1. 让学生**看懂每一分**：成绩、排名、各科档位、原卷、评分标准、成长曲线。
2. 让日常练习**有反馈**：作品上传后有老师打分、标签和评语，问题可以被统计和追踪。
3. 让补短板**有抓手**：范画库对照、画室工具箱自查、教学视频和题库。
4. 沿用音乐之路的通用能力（AI 助手、课件云盘、视频、笔记、收藏、校圈、智慧校园），内容全部换成美术场景。

v1 为**演示版**：全部数据来自本地演示后端，接口路径与阅卷系统真实契约保持一致，后续关闭演示开关即可对接。

## 2. 目标用户

| 角色 | 典型诉求 |
| --- | --- |
| 美术艺考生（主用户） | 模考出分后想知道「差在哪」；想看自己的原卷和高分卷对比；日常作业希望得到具体点评；想知道自己是不是在进步 |
| 任课 / 阅卷老师 | 快速批改学生日常作品；看班级考试整体情况，找出需要关注的学生 |
| 班主任 | 班级考勤、请假、作业、家校沟通（智慧校园） |
| 宿管 | 查寝、晚归、宿舍动态（智慧校园） |
| 画室 / 学校管理员 | 班级、老师、学生、通知、排课、签到管理（智慧校园） |

## 3. 学生核心闭环

```
模考出分 → 学情中心看成绩/排名/档位
        → 原卷查看 + 评分标准（档位样图）+ 范画库高分卷对比，找到差距
        → 日常作品上传 → 老师打分、标签、评语（可批注改画）
        → 「我的高频问题」汇总标签 → 推荐范画与视频
        → 画室工具箱自查明暗、比例、色彩 → 速写计时练习
        → 成长曲线验证进步
```

## 5. 功能清单

### P0（v1 必须）

**学情中心**
- 学生：总览（最近一次考试、累计测评、各科档位）、考试列表、成绩报告（总分环、总排名 / 校区排名、超过 X% 考生、各科分数 / 档位 / 得分率 / 较上次变化、优势与待提升）、原卷查看（水印、缩放）、评分标准（A–K 档分数段、说明、样图）、成长曲线（分数 / 排名切换，总分与单科）。
- 老师：班级学情（选择考试和科目：参考人数、均分、最高、最低、中位数、分数段分布、校区对比、排名名单 → 学生报告）。

**作品档案 / 作品点评**
- 学生：统计、按月时间线、状态筛选、上传（1–9 张、科目、作画日期、说明）、详情（多老师点评、最终分）。
- 老师：待点评 / 已点评队列、打分（满分与其他老师一致）、标签（≤8）、评语（≤2000 字）、保存并下一份、标签管理（≤50 个、8 色）。

**范画库**
- 分类：素描（石膏 / 静物 / 头像）、色彩（静物 / 风景）、速写（单人 / 组合）、高分卷。
- 搜索、筛选、大图缩放、收藏、与我的作品对比、一键进入「临摹网格」。

**画室工具箱**（完全离线，2.0 扩展为三组 17 个）
- 看画分析：明度检查（灰度、色阶、黑白剪影）、眯眼模糊、色块简化、冷暖分布、轮廓线稿、镜像翻转（含反相）、取色与色卡、比例测量、构图网格、透视辅助、头像比例（三庭五眼）。
- 练习训练：速写计时练习（30 秒 – 10 分钟，参考图轮播，结束回顾）、人体比例参考、明度排序训练。
- 备考助手：考试倒计时、综合分计算器（按省份公式，结果仅供参考）、考场物品清单。

### P1（v1 增强）

- 对比查看：左右分屏 + 拖动分割线（原卷 vs 档位样图 / 高分卷，作品 vs 范画）。
- 老师批注改画：在学生作品上画笔批注，学生可开关查看（演示版保存在本机）。
- 我的高频问题：汇总点评标签 Top 5，推荐对应范画与视频。
- 美术常识题库：美术史、名作鉴赏、色彩、透视。
- AI 作品分析：附图提问，返回结构化点评（构图 / 造型 / 明暗 / 色彩）。

### P2（后续）

- 对接真实阅卷后端与平台后端、账号打通。
- 老师批注上云、点评语音。
- 院校库与招生分数线（需权威数据源）。

## 11. 2.0 打磨（2026-11-07）

### 11.1 品牌与统一风格

- 艺考网标志：侧栏（收起时显示图形标）、登录 / 注册 / 忘记密码页、App 图标与网页图标；应用名仍为「绘画星球」。
- 设计规范 `docs/设计规范.md` + 组件库 `lib/core/ui`（按钮、页签、筛选、卡片、列表行、输入、下拉、弹窗、抽屉、轻提示、空状态、骨架屏、头像、统计块、进度条、课程卡、步骤条等），与机构端（阅卷系统）同一套色板与字阶。全站去掉点击动效，选中即时切换，只有浮层淡入（不超过 200ms）。
- AI 助教改名「小美同学」；首页课程卡标签完整换行显示。

### 11.2 新功能

- 美术书刊：列表（分类、排序、搜索）、详情（简介、目录、相关书刊）、双页阅读器（翻页、目录与书签、自动保存进度）、书架（继续阅读 / 收藏）；首页「精选书刊 / 继续阅读」，顶部搜索与我的收藏都支持书刊。
- 画室工具箱扩展到 17 个工具（见第 5 节）。
- 综合分预估（我的学情）：专业成绩取最近一次已出分的考试，文化课预估分由学生填写，显示计算过程与距目标的差距，始终注明仅供参考。

### 11.3 按身份的首页

| 身份 | 首页重点 |
| --- | --- |
| 学生 | 今日课程、今日练习（按高频问题和弱项科目推荐工具或范画）、最近点评、学情速览、精选书刊 / 继续阅读 |
| 任课老师 | 今日课程、画室学情速览、作品点评（待点评 N 件） |
| 班主任 | 今日课程、画室学情速览、今日待办（待点评作品、班级工作台、未读消息） |
| 宿管 | 今日待办（晚查寝 / 晨查寝时间、到岗打卡、宿管请假、未读消息），不显示学情与成绩 |
| 管理员 | 今日待办（教师请假审批、小课签课确认、排课与课表、未读消息）、画室学情速览 |

### 11.4 体验细节

- 通知点开直达对应页面（学情、作品、书刊、智慧校园、工具箱）并标为已读。
- 顶栏「演示版」标识，点开说明演示数据与重置方式。
- 新手引导：各身份第一次进入首页时用 3–4 步介绍常用入口，可跳过，帮助页可重新打开。
- 点击区域：顶栏、侧栏与弹窗 / 抽屉的关闭按钮统一 40×40；全站最小字号 12。
- 演示时间固定落在白天（`DemoClock`），夜间打开也不会出现深夜上课、凌晨点评。
- 跨页面数据统一：首页与智慧校园课表同源；排名分母注明「人参考」；查寝时间、待审批数、班级人数在各页一致；智慧校园「考评管理」的评分同步到阅卷系统，复核后在「班级学情」发布。
- 校圈举报与治理：学生和老师可以举报别人的动态；管理员在智慧校园「校圈治理」里按「待处理 / 已处理 / 全部动态」处理，删除需填写原因并二次确认，工作台「校圈待处理」与页签同一个数。独立的「校圈」页对管理员仍是普通校圈，可发布学校动态。
