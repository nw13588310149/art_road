# 美术之路 v1（演示版）产品规划

> 版本：v1.0 · 2026-11-07
> 工程：`D:\桌面\阅卷系统\art-road`（由「音乐之路」2.0 复制改造）
> 关联系统：艺考网阅卷系统（机构端 grading-web、扫描端 examScan、学情小程序、报名 H5）

## 1. 背景与目标

艺考网阅卷系统已经覆盖了「办考 → 扫描 → 评级评分 → 仲裁 → 查分 → 归档」的完整链路，但学生和老师在日常学习中缺少一个围绕这些数据展开的大屏学习工具。音乐之路已经验证过 iPad 横屏学习 App 的形态（左侧导航、顶栏、智慧校园五角色）。

美术之路的目标：

1. 让学生**看懂每一分**：成绩、排名、各科档位、原卷、评分标准、成长曲线。
2. 让日常练习**有反馈**：作品上传后有老师打分、标签和评语，问题可以被统计和追踪。
3. 让补短板**有抓手**：范画库对照、画室工具箱自查、教学视频和题库。
4. 沿用音乐之路的通用能力（AI 助手、课件云盘、视频、笔记、收藏、校圈、智慧校园），内容全部换成美术场景。

v1 为**演示版**：全部数据来自本地演示后端，接口路径与阅卷系统真实契约保持一致，后续关闭演示开关即可对接。

## 2. 目标用户

| 角色 | 典型诉求 |
| --- | --- |
| 美术艺考生（主用户） | 模考出分后想知道「差在哪」；想看自己的原卷和高分卷对比；日常作业希望得到具体点评；想知道自己是不是在进步 |
| 任课 / 阅卷老师 | 快速批改学生日常作品；看班级考试整体情况，找出需要关注的学生 |
| 班主任 | 班级考勤、请假、作业、家校沟通（智慧校园） |
| 宿管 | 查寝、晚归、宿舍动态（智慧校园） |
| 画室 / 学校管理员 | 班级、老师、学生、通知、排课、签到管理（智慧校园） |

## 3. 学生核心闭环

```
模考出分 → 学情中心看成绩/排名/档位
        → 原卷查看 + 评分标准（档位样图）+ 范画库高分卷对比，找到差距
        → 日常作品上传 → 老师打分、标签、评语（可批注改画）
        → 「我的高频问题」汇总标签 → 推荐范画与视频
        → 画室工具箱自查明暗、比例、色彩 → 速写计时练习
        → 成长曲线验证进步
```

## 5. 功能清单

### P0（v1 必须）

**学情中心**
- 学生：总览（最近一次考试、累计测评、各科档位）、考试列表、成绩报告（总分环、总排名 / 校区排名、超过 X% 考生、各科分数 / 档位 / 得分率 / 较上次变化、优势与待提升）、原卷查看（水印、缩放）、评分标准（A–K 档分数段、说明、样图）、成长曲线（分数 / 排名切换，总分与单科）。
- 老师：班级学情（选择考试和科目：参考人数、均分、最高、最低、中位数、分数段分布、校区对比、排名名单 → 学生报告）。

**作品档案 / 作品点评**
- 学生：统计、按月时间线、状态筛选、上传（1–9 张、科目、作画日期、说明）、详情（多老师点评、最终分）。
- 老师：待点评 / 已点评队列、打分（满分与其他老师一致）、标签（≤8）、评语（≤2000 字）、保存并下一份、标签管理（≤50 个、8 色）。

**范画库**
- 分类：素描（石膏 / 静物 / 头像）、色彩（静物 / 风景）、速写（单人 / 组合）、高分卷。
- 搜索、筛选、大图缩放、收藏、与我的作品对比、一键进入「临摹网格」。

**画室工具箱**（完全离线）
- 明度检查：灰度 + 3 / 5 阶色调分离，检查黑白灰关系。
- 镜像翻转：水平 / 垂直翻转，检查比例与透视。
- 构图网格：九宫格、N×M、对角线，颜色与透明度可调。
- 取色与色卡：点击取色（HEX / RGB / HSB / 冷暖），自动提取 6 色色卡。
- 速写计时练习：30 秒 – 10 分钟，参考图轮播，结束回顾。
- 考试倒计时：自定义联考 / 校考日期。

### P1（v1 增强）

- 对比查看：左右分屏 + 拖动分割线（原卷 vs 档位样图 / 高分卷，作品 vs 范画）。
- 老师批注改画：在学生作品上画笔批注，学生可开关查看（演示版保存在本机）。
- 我的高频问题：汇总点评标签 Top 5，推荐对应范画与视频。
- 美术常识题库：美术史、名作鉴赏、色彩、透视。
- AI 作品分析：附图提问，返回结构化点评（构图 / 造型 / 明暗 / 色彩）。

### P2（后续）

- 对接真实阅卷后端与平台后端、账号打通。
- 老师批注上云、点评语音。
- 院校库与招生分数线（需权威数据源）。

## 6. 与阅卷系统的接口映射

| 功能 | 接口 | 状态 |

## 8. 非功能要求

- iPad 横屏优先（设计基准 1180×820），Web 端可演示。
- 隐私：身份证号一律脱敏；原卷带姓名水印；演示数据均为虚构。
- 工具箱完全离线；图片处理在后台计算，不卡界面。
- 品牌：艺考网色板，主色 `#715EFE`；科目色 素描 `#4A74D6` / 色彩 `#3B9A6E` / 速写 `#1F8FA8`。
