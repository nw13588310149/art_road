# 美术之路 v1 · 后端缺口清单

v1 演示版的全部数据来自本地演示后端（`lib/core/demo/`）。关闭演示模式（`--dart-define=DEMO_MODE=false`）后，App 直接请求下面两套真实接口。本清单列出两套接口里**已经可用**、**需要后端补齐**和**需要产品决策**的部分，供排期使用。

依据：阅卷系统接口文档、`查分项目/docs/backend/2026-11-07/后端交接清单.md`、`查分项目/uni-app/api/*`（已对接正式服的学情小程序）。

## 一、两套接口

| 客户端 | 地址 | 鉴权 | 用到的模块 |
| --- | --- | --- | --- |
| 平台接口 `apiClientProvider` | `https://api-v2.yyzl0931.com/` | 请求头 `app-token` + `schoolId` | 账号、首页资讯、校园课件、云盘、视频、笔记、收藏、题库、AI、校圈、智慧校园、个人中心 |
| 阅卷接口 `markingApiClientProvider` | `https://exam-api.yyzl0931.com/` | 学生 `app-token`，老师 `school-token` | 学情中心、班级学情、作品档案、作品点评、范画库 |

两套接口统一返回 `{code, msg, data}`，`code == 0` 为成功。

## 二、阅卷接口

### 已上线，可直接对接

| 功能 | 接口 |
| --- | --- |
| 学情总览 | `GET /app/study/overview` |
| 考试列表 | `GET /app/study/exams?status=ALL\|PUBLISHED\|MARKING&current=&size=` |
| 成绩报告 | `GET /app/study/exams/{examId}` |
| 原卷 | `GET /app/study/exams/{examId}/papers/{subjectId}`（签名 URL，客户端加姓名水印） |
| 成长曲线 | `GET /app/study/growth?subjectName=&metric=SCORE\|RANKING` |
| 作品档案 | `GET /app/artworks`、`GET /app/artworks/{id}`、`GET /app/artworks/statistics`、`POST /app/artworks`、`POST /app/artworks/images/upload` |
| 作品点评 | `GET /school/teacher/artworks`、`GET /school/teacher/artworks/{id}`、`GET /school/teacher/artworks/statistics`、`POST /school/teacher/artworks/review?next=` |
| 点评标签 | `GET/POST /school/teacher/tags`、`POST /school/teacher/tags/update`、`POST /school/teacher/tags/delete?id=` |
| 老师查看学生 | `GET /school/teacher/students/{archiveId}/exams/{examId}`、`GET /school/teacher/students/{archiveId}/curve` |

对接时请留意：
- 作品点评的盲评规则（本人提交前看不到其他老师的分数与评语）由后端控制，前端按返回字段展示，演示数据已按同样规则造数。
- `growth` 与 `curve` 的数据点需要补 `participantCount`（交接清单 H-09），前端已读取该字段，人数不一致时会提示「前 X%」口径。

### 需要后端补齐

| 优先级 | 功能 | App 调用的接口 | 现状与建议 |
| --- | --- | --- | --- |
| P0 | 班级学情（任课老师） | `GET /school/teacher/exams` | 真实后端没有这个接口。现有 `POST /school/exam/list`、`POST /school/score-query/page`、`POST /school/marking/gradeRule` 只对管理员和教务开放，任课老师调用返回 403。建议新增 `GET /school/teacher/exams`（老师指导学生参加过的考试，字段同演示数据：`examId`、`examName`、`examTime`、`reviewStatus`、`participantCount`、`subjects[]`），并给老师开放限定在指导学生范围内的成绩分页与评分档位；或直接提供交接清单 H-07 的聚合接口 `GET /school/exams/{examId}/analysis` 的老师版。 |
| P0 | 范画库（学生端） | `GET /app/gallery/categories`、`GET /app/gallery/works?subject=&category=&keyword=&sort=&current=&size=`、`GET /app/gallery/works/{id}`、`POST /app/gallery/works/{id}/favorite` | 学生端没有范画接口。机构端已有资料库 `/school/resources?favorite=true`，建议基于它开放学生只读接口：只返回机构标记为「范画」的资料，字段含 `id`、`title`、`subject`、`category`、`imageUrl`、`thumbnailUrl`、`grade`（档位）、`score`、`teacherName`、`examName`、`description`、`tags[]`、`favorite`。 |
| P1 | 评分标准（学生端） | `GET /app/study/exams/{examId}/subjects/{subjectId}/standard` | 机构端有 `POST /school/marking/gradeRule`，学生端没有。建议只读开放：满分、A–E 档位区间、档位说明与样卷图。不含评委打分。 |
| P1 | 老师批注改画 | `GET/POST /school/teacher/artworks/{id}/annotations` | 交接清单 H-10 写明「图片圈画批注等产品排期后另出需求」。前端已完成：笔迹按图片宽高归一化保存（`color`、`width`、`points[[x,y]]`、`imageIndex`），学生端在作品详情里以 `annotations` 字段读取并可开关显示。演示版保存在本机。 |
| P1 | 我的高频问题 | `GET /app/artworks/insights` | 后端没有。返回：已点评作品数、平均分、最佳 / 待加强科目、标签频次 Top N、每个高频标签的练习建议。接口未上线时前端显示空状态，不影响作品列表。也可以先由前端基于作品列表与详情的标签自行汇总。 |
| P2 | 范画对比我的原卷 | 复用 `overview` 与 `exams/{examId}` | 无需新接口；范画库接口上线后即可使用。 |

### 需要产品确认

- 学生端评委打分明细：真实接口对学生返回 403。App 的评委明细只在老师端（`ui/staff/`）展示，学生端只显示最终得分、档位与评语，与现状一致。是否对学生开放，需要产品决定。
- 机构统一满分、评分档位、公共标签库（交接清单 H-10）：上线后前端无需改动，作品级 `maxScore` 会自动锁定满分输入框。

## 三、平台接口

App 的通用模块沿用原平台（音乐之路，api-v2）的接口协议，路径保持不变：账号与内容在 `/app/user/*`、`/app/common/*`、`/app/msg/*`、`/app/courseware/*`，智慧校园在 `/app/school/v2/{student,teacher,manager,dormitory,chat,posts,user}/*`。演示数据按这些协议造数，内容替换成美术。

需要决策：
1. **美术版用哪个平台后端**：独立部署一套美术版平台后端，还是复用 api-v2 并按学校隔离内容？复用时首页资讯、视频、课件、题库等内容要按「美术」打标签筛选。
2. **账号打通**：平台账号（手机号 + 密码，`app-token`）与阅卷系统的学生 / 老师账号是两套。需要确定绑定方式，例如：
   - 平台登录后用手机号换取阅卷 `app-token` / `school-token`；
   - 或阅卷系统作为统一身份源，平台接受阅卷 token。
   演示版用 `demo.<role>.<手机号>` 形式的令牌同时代表两边身份，接入真实接口前必须替换。
3. **角色映射**：智慧校园的学生、任课老师、班主任、宿管、管理员五种角色来自平台；作品点评、班级学情的老师身份来自阅卷系统。两边的老师需要一一对应。

## 四、演示版专有、接入真实接口前需要处理

| 项目 | 位置 | 处理方式 |
| --- | --- | --- |
| 体验身份登录、重置演示数据 | `login_page.dart` 中 `kDemoMode` 分支 | `DEMO_MODE=false` 时自动隐藏 |
| 演示令牌 `demo.<role>.<mobile>` | `DemoAccounts` | 真实登录后不再出现 |
| 本地媒体服务（上传文件、示例图片、视频） | `lib/core/demo/media/` | `DEMO_MODE=false` 时不启动；文件地址改用平台 `configList` 下发的 `fileServerUrl` |
| AI 作品分析 | `interaction_ai_tutor.dart` | 演示版只返回分析模板并注明「没有真正识别图片」；正式版需要接入支持图片理解的模型 |
| 示例图片、视频、Logo | `assets/demo/**`、`assets/images/home/art/` | 为演示生成或制作，正式上线前替换成画室授权的作品与品牌素材 |
