## 页面统一标准

每个页面应回答当前对象和范围、数据依据、主要判断、下一步动作四个问题。数据表明确单位与统计区间；缺失值与零区分。首用空内容提供起步入口，筛选为空提供清空操作，加载失败提供重试，权限不足解释可行路径。按钮必须产生业务结果，不能点击后才提示内部接口未提供。

视觉以现有组件库及用户批准稿为准：相同层级使用相同字阶，图像真实对应业务对象，按钮保留明确语义，横屏两个尺寸检查拥挤、遮挡与溢出。主要页面保持各自的任务结构，不统一为同一种卡片。

## 集市交易设计

- 买家：浏览和筛选 → 商品详情与作者 → 核对许可或实体规格 → 结算 → 待付款 → 模拟支付 → 履约 → 完成 → 评价或售后。
- 数字授权：选择许可范围；订单保存价格、许可条款、交付文件快照；支付完成后提供交付和许可凭证；公开预览与订单交付权限分开。
- 实物：数量、库存、运费和收货地址进入订单；待付款占用库存，取消或超时释放；卖家发货、买家查看物流与确认收货；下架不影响已有订单履约。
- 卖家：商品草稿、发布校验、提交审核、在售、下架、编辑；查看订单并发货，处理售后。修改商品不改历史订单。
- 平台：按管理员权限审核商品、处理举报与售后争议；操作留记录。普通买卖双方不得越权审核或查看他人订单。
- 财务：金额统一用分，结算明细与订单状态一致。模拟支付和退款明确标识，不伪装真实扣款；正式支付、签名回调、资金结算、实名认证、内容/权属审核、物流和存储由后端按接口契约接入。
- 状态验证：防重复提交、重复支付/退款、售罄、已下架、价格变更、取消、超时、失败重试、账户切换和刷新恢复。

## iPad 工具交互

工具入口替换角色形象和宽抽屉；工具轨为单列、触控区至少 44px。工具选择与参数显示是两个状态：关闭参数不结束工具，结束工具明确清除页面效果。测量和取色进入精确操作时让出画面，始终提供退出/恢复入口；全屏工具和业务模态窗口隐藏外层工具。路由切换清理页面效果，完整工具箱会话保留当前原图。取色只采样业务画面，不能把工具栏或参数面板采入结果；测量标注页面比例，不能冒充实体尺寸。

## 学生短板和教学跟进

同一科目内分析多人评价，并明确聚合规则、样本数和时间范围。弱项返回作品、评价老师、日期与关联分项；展示近期变化及可追溯证据。首页给主要问题和下一步，成长页提供科目/维度筛选与作品明细。小课件通过知识点关联练习，提交保留练习来源；“已改善”需要可解释的近期依据。

## 审查记录

独立诊断已发现：短板跨科目混合、多人评价口径不完整；集市缺买卖双方履约；工具抽屉遮挡；教师列表/关注名单缺处置状态；小课件阅读到练习断点；部分通知/题库入口点击后仅显示暂不可用。分别纳入对应模块，不把旧截图审查称为全部路由实测通过。

最终验收包含分析、测试、1180×820 与 1024×768 的角色页面截图、关键交互断言、业务状态回读和再次全流程检查。每个通过结论列明实际覆盖范围与报告，原生设备能力另行标注。
