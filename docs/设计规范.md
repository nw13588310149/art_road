# 美术之路设计规范（组件库 v1）

面向美术艺考生、画室老师与教务的横屏 iPad 应用（设计基准 1180×820）。布局和通用组件以经过验证的音乐之路横屏版为参照。美术之路使用艺考网标识、现有美术素材和品牌紫 #715EFE。主应用的业务内容由外壳统一提供白色圆角底板。

- 代码：`lib/core/ui/`，页面只引入 `lib/core/ui/ui.dart`。
- 演示：路由 `/design-system`（`RoutePaths.designSystem`）。演示模式下「操作指南」页头右侧有「组件库（演示）」入口，演示页逐个展示组件的全部变体与状态。
- 外壳内 `DashboardScaleScope.ui()` 原样返回像素值，组件库直接使用逻辑像素，不依赖 `DashboardScaleScope`，登录页等外壳之外的页面同样可用。

---

## 1. 原则

1. **一套色板。** 所有颜色来自 `AppColors`；`ArtColors` / `ArtText` 只是它们的旧名。页面里不再写十六进制颜色。
2. **品牌紫要省着用。** 只给主操作、选中态、关键数字和链接。一个区域只放一个品牌主按钮。
3. **平放。** 卡片静止时是白底 + 1px `#F3F2F3` 描边，没有阴影。只有浮起的东西（弹窗、抽屉、下拉、轻提示）有柔和阴影。
4. **点了就变，不做动画。** 没有水波纹、按压高亮、缩放、滑动的选中块。选中、开关、页签立即切换。只有浮层可以在 200ms 内淡入或滑入。
5. **层级靠字阶和颜色。** 标题、正文、辅助文字分别用字阶与三级文字色区分，不靠堆加粗、描边或底色。
6. **每块数据都有三种状态。** 加载、空、错误都要设计，且与最终布局同尺寸。
7. **中文界面。** 中文标点，数字用 Manrope，界面文案不用感叹号，最小字号 12。

## 3. 交互与动效

- **所有可点元素都用 `AppPressable`**：不透明命中区域、Web 上指针光标、按钮语义；没有任何按压反馈。
- **禁用**：整体 40% 不透明度，不响应点击，光标不变。`onTap: null` 也视为禁用（按钮、图标按钮）。
- **选中**：分段、页签、筛选、开关、复选框在同一帧切换，不做滑块、渐变、缩放。
- **焦点**：输入框聚焦时描边立即变品牌紫，出错时立即变红，不做过渡。
- **浮层**：弹窗淡入 180ms，抽屉从右滑入 180ms，下拉淡入 180ms，轻提示淡入下滑 180ms，均不超过 200ms（`AppMotion.overlay` / `overlayMax`）。
- **主题兜底**：`AppTheme.light` 已去掉 Material 按钮、InkWell、Switch、Checkbox、Radio、Slider、Chip、ListTile、TabBar、PopupMenu 的水波纹与按压叠色，`focusColor` 透明；弹窗圆角 12、底部面板顶部圆角 16、遮罩 `scrim`、Tooltip 墨色底 12 号字。Material 自带的开关、复选框、TabBar 指示条仍有切换动画，新页面改用组件库的 `AppSwitch` / `AppCheckbox` / `AppTabs`；不得不用 `TabBar` 时给 `TabController` 设 `animationDuration: Duration.zero`。
- 加载转圈（按钮 loading、`AppLoadingIndicator`）属于状态指示，不在禁止之列。

## 4. 组件

每个组件一个文件，参数统一用命名参数：点击 `onTap`，取值 `value` + `onChanged`，禁用 `enabled`。

### AppPressable 点击底座
- 用途：任何可点的块（卡片、行、图标、自定义按钮）。替代 `InkWell` / `GestureDetector`。
- API：`AppPressable({required Widget child, VoidCallback? onTap, VoidCallback? onLongPress, bool enabled = true, String? semanticLabel, bool? selected, bool? checked, bool? toggled})`
- 要：只有图标没有文字时传 `semanticLabel`。不要：在外面再包 `InkWell` 或自己加按压变色。

### AppButton 按钮
- 主按钮 `primary` 使用品牌紫渐变，`secondary` 用白底灰描边。云盘与笔记用 `floating`，40 高、圆角 8，并可通过 `iconAsset` 使用旧版图标。`quiet`、`danger` 和 `text` 分别用于弱操作、危险操作和文字链接。
- 尺寸：`md` 45 高 16 号字，`sm` 34 高 14 号字，圆角 12。
- API：`AppButton({required String label, required VoidCallback? onTap, AppButtonVariant variant = primary, AppButtonSize size = md, IconData? icon, String? iconAsset, bool loading = false, bool enabled = true, bool expand = false})`
- 要：主操作放最右；弹窗底部两个按钮平分宽度。不要：一屏多个 primary；用 danger 做普通提交；在列表行里用 md。

### AppIconButton 图标按钮
- md 40 方形圆角 12，sm 34 方形圆角 8。`filled` 默认浅灰底，`background` 可设为白底，`false` 时无底（页头、弹窗右上角关闭）。
- 顶栏、侧栏和弹窗 / 抽屉右上角的关闭这类单独出现的图标按钮用 md 40，保证点击区域；sm 只用于列表行、卡片内的紧凑操作。
- API：`AppIconButton({required IconData icon, required String semanticLabel, required VoidCallback? onTap, AppButtonSize size = md, bool filled = true, Color background = surfaceSubtle, Color color = ink, int badgeCount = 0, bool enabled = true, bool showTooltip = true})`
- `semanticLabel` 必填，同时是读屏文字与悬停提示；`badgeCount > 0` 显示红色计数（超过 99 显示 99+）。
- `AppIconButton.asset` 用于顶栏帮助、通知、设置等原版图标。`AppIconButton.back` 使用 32 方形白底描边和左箭头。

### AppSegmented 分段控件
- 用于卡片或工具栏中的互斥视图。浅灰轨道搭配实底选中块，默认品牌紫白字。收藏与笔记使用 `neutral` 白色选中块。
- md 32 高，sm 30 高，均为 13 号字。`expand` 等分父级宽度。
- `trackColor` 和 `selectedColor` 支持旧版中已有的分段样式，`AppSegment` 可带计数角标。
- 不要：超过 5 段（改用 `AppTabs` 或 `AppSelect`）；做页面级主导航。

### AppTabs 页面页签
- 用于页面级内容切换。默认 44 高，选中使用品牌文字和 28×3 圆角指示条，数量以括号显示。
- 视频分类使用 `textOnly`。36 高，选中字号 18，未选字号 14，切换时保持各项宽度。
- 页签多于可视宽度时由页面包一层横向 `SingleChildScrollView`。

### AppChip 筛选胶囊
- 用途：可多选、可取消的筛选条件。30 高胶囊；未选白底灰描边墨色字，选中 `brandWash` 底 + 品牌紫字 + 品牌紫描边。
- API：`AppChip({required String label, required bool selected, required VoidCallback? onTap, IconData? icon, bool enabled = true})`
- 不要：用它做互斥视图切换（用 `AppSegmented`）。

### AppTag 标签
- 只读小胶囊：22 高、12 号字、浅底深字，按内容取宽，从不截断；可能变窄的位置用 `Wrap` 排列。
- 色调：`AppTone.neutral / brand / success / warning / danger / info`；自定义 `color`（浅底自动 12%）或 `color + background`；`dotColor` 显示前置圆点（大课 / 小课）；`icon` 前置图标。
- API：`AppTag({required String label, AppTone tone = neutral, Color? color, Color? background, Color? dotColor, IconData? icon})`；`AppTag.subject(String subject, {bool muted = false})`
- 不要：放进会压缩它的 `Row`；用标签做按钮。

### AppStatusTag 状态
- 圆点 + 文字，无底色。约定：进行中 `brand`，已完成 `success`，需处理 / 待开始 `warning`，失败 / 缺勤 `danger`，未开始 / 已结束 `neutral`。
- API：`AppStatusTag({required String label, AppTone tone = neutral, Color? color})`
- 要：状态总有文字，不能只靠颜色。

### AppBadge 角标
- 红色计数气泡（18 高，Manrope 12）或 8px 红点；计数为 0 且无文字时不占位。
- API：`AppBadge({int count = 0, String? label, int max = 99})`；`AppBadge.dot()`

### AppCard 卡片
- 白底 + 1px `lineSoft` 描边 + 圆角 16，静止无阴影。可带标题行（`title16` + `caption12` 副标题 + 右侧 `trailing`）。卡片内的浅灰子卡片用 `color: AppColors.surfaceSubtle, bordered: false`。
- API：`AppCard({required Widget child, String? title, String? subtitle, Widget? trailing, EdgeInsetsGeometry padding = EdgeInsets.all(16), VoidCallback? onTap, Color color = surface, double radius = 16, bool bordered = true})`
- 不要：给卡片加阴影或渐变底；卡片套卡片都用白底描边。

### AppListRow 列表行
- 左侧图标 / 头像 + 标题（`body14Strong`）+ 副标题（`caption12`）+ 右侧内容 + 可选箭头，最小高 48；`divider` 在底部画细线。
- API：`AppListRow({required String title, String? subtitle, Widget? leading, Widget? trailing, bool chevron = false, VoidCallback? onTap, bool enabled = true, bool divider = false, EdgeInsetsGeometry padding = EdgeInsets.symmetric(horizontal: 16, vertical: 12)})`
- 要：可进入下一级的行显示 `chevron`。

### AppSectionHeader 区块标题
- `title20` 标题 + 可选 `caption12` 副标题 + 右侧「更多 ›」（三级文字色）或自定义 `trailing`。
- API：`AppSectionHeader({required String title, String? subtitle, VoidCallback? onMore, String moreLabel = '更多', Widget? trailing})`

### AppPageHeader 页面工具栏
- 仅呈现返回、操作和筛选。`title` 与 `subtitle` 用于无障碍识别，没有控件时工具栏收起。记录名称和识别信息放在内容卡里。
- 右侧操作间距 8，`bottom` 可放筛选、搜索或页签。

### AppSearchField 搜索框
- 白底圆角 12，使用旧版放大镜图标。常规 36 高，紧凑 30 高，全局顶栏 `toolbar` 为 40 高。输入后可清空，聚焦立即显示品牌色描边。
- API：`AppSearchField({TextEditingController? controller, String hint = '搜索', ValueChanged<String>? onChanged, ValueChanged<String>? onSubmitted, VoidCallback? onCleared, AppControlSize size = md, bool toolbar = false, bool autofocus = false, FocusNode? focusNode, bool enabled = true})`
- 宽度由父级决定，放在 `Row` 里时外包 `SizedBox` 或 `Expanded`。

### AppInputField 表单输入框
- 可选标题（`required` 时加红色星号）、占位、错误提示（描边转红 + 下方红字）、字数计数（`已输入/上限`，Manrope）、多行。单行 34 高（sm 30），白底 1px `line` 描边，只读为浅灰底。
- API：`AppInputField({TextEditingController? controller, String? label, String? hint, String? errorText, int? maxLength, bool multiline = false, int minLines = 3, int maxLines = 6, ValueChanged<String>? onChanged, ValueChanged<String>? onSubmitted, TextInputType? keyboardType, TextInputAction? textInputAction, List<TextInputFormatter>? inputFormatters, bool obscureText = false, bool required = false, bool enabled = true, bool readOnly = false, bool autofocus = false, FocusNode? focusNode, AppControlSize size = md})`
- 说明：`lib/core/widgets/app_text_field.dart` 已有同名的 `AppTextField`（`TextField` 子类，40 多处使用），为避免同名冲突，表单组件命名为 `AppInputField`；聊天输入条这类需要完全自定义外观的输入仍直接用 `AppTextField`。
- 要：错误提示写清楚怎么改（「准考证号应为 10 位数字」）。不要：用占位文字代替标题。

### AppSelect 下拉选择
- 34 高（sm 30）字段，点击后在下方（空间不够时在上方）弹出菜单；菜单白底圆角 12，行高 36，选中项品牌紫字 + 对勾，不加底色；淡入 180ms。
- API：`AppSelectOption<T>({required T value, required String label, bool enabled = true})`；`AppSelect<T>({required List<AppSelectOption<T>> options, required T? value, required ValueChanged<T> onChanged, String hint = '请选择', AppControlSize size = md, bool enabled = true, double menuMaxHeight = 280})`
- 选项少于等于 4 个且常用时优先 `AppSegmented`。

### AppSwitch 开关
- md 42×26 / sm 34×20；开为品牌紫，关为 `line` 灰，白色圆钮立即移位，没有滑动。
- API：`AppSwitch({required bool value, required ValueChanged<bool>? onChanged, bool enabled = true, AppControlSize size = md, String? semanticLabel})`

### AppCheckbox 复选框
- 16×16 圆角 4，未选 1.5px 灰描边，选中品牌紫实底 + 白色对勾；带 `label` 时文字也可点击，整行至少 32 高。
- API：`AppCheckbox({required bool value, required ValueChanged<bool>? onChanged, String? label, bool enabled = true, String? semanticLabel})`

### AppDialog 弹窗 · showAppDialog · showAppConfirm
- 白底圆角 24，浅紫渐变页头与居中的 `title20` 标题 + `body14` 二级色说明 + 自定义内容（超高滚动）+ 底部按钮（默认平分宽度）。没有底部按钮时右上角显示关闭。宽 420（`AppSize.dialogWide` 560）。
- API：
  - `AppDialog({required String title, String? message, Widget? child, List<Widget> actions = const [], bool fillActions = true, double width = 420, bool? showClose})`
  - `Future<T?> showAppDialog<T>({required BuildContext context, required WidgetBuilder builder, bool barrierDismissible = true, bool useRootNavigator = true})`
  - `Future<bool> showAppConfirm({required BuildContext context, required String title, String? message, String confirmLabel = '确定', String cancelLabel = '取消', bool danger = false, bool barrierDismissible = true})`
- 不依赖 `DashboardScaleScope`，登录、注册等外壳之外的页面也能用；在外壳内调用时会把 `DashboardScaleScope` 带进弹窗，内容里暂未迁移的旧组件仍能工作。旧的 `showConfirmDialog` / `showInfoDialog`（`scaled_dialog.dart`）只能在外壳内使用，新代码改用这里的函数。
- 要：会改变阶段或不可撤销的操作用确认弹窗，说明影响范围和后果；危险操作 `danger: true`。不要：用弹窗承载长表单（改用抽屉）。

### AppDrawer 抽屉 · showAppDrawer
- 右侧整高面板，宽 420（`AppSize.drawerWide` 560），左侧圆角 16；标题栏（标题 + 副标题 + 关闭）+ 可滚动内容 + 可选底部按钮（靠右）。从右滑入 180ms。
- API：`AppDrawer({required String title, required Widget child, String? subtitle, List<Widget> actions = const [], double width = 420, EdgeInsetsGeometry padding, VoidCallback? onClose})`；`Future<T?> showAppDrawer<T>({required BuildContext context, required WidgetBuilder builder, bool barrierDismissible = true})`
- 用于原地办理：名单、选老师、筛选、详情、较长表单。

### AppToast 轻提示
- 唯一的样式：顶部居中白色浮条（圆角 12，`overlay` 阴影），左侧图标区分成功（绿）/ 失败（红）/ 信息（紫），14 号字最多两行，2.2 秒后消失；同一时间只有一条。
- API：`AppToast.show(BuildContext context, String message, {Duration duration, AppToastType? type})`；`AppToast.showSuccess / showError / showInfo(context, message)`；`AppToastType { success, error, info }`。
- `lib/core/widgets/app_toast.dart` 现在只是转发，旧调用 `AppToast.show(context, msg)` 不用改；不传 `type` 时仍按文案自动判断成功 / 失败。

### AppEmptyState 空状态 · AppErrorState 错误状态
- 紧凑居中：48×48 圆角 12 的图标块或 160×160 的通用插图 + `body14Strong` 标题 + `body13` 三级色说明 + 可选操作（quiet sm 按钮），父级过矮时内容可滚动。
- API：`AppEmptyState({required String title, String? description, IconData icon = Icons.inbox_outlined, String? illustration, String? actionLabel, VoidCallback? onAction, Widget? action, Color iconColor, Color iconBackground})`；`AppErrorState({String title = '加载失败', String? description, VoidCallback? onRetry, String retryLabel = '重试', IconData icon = Icons.cloud_off_rounded})`
- 空状态标题说清楚这里会有什么，说明告诉用户怎么让它出现；错误状态说明原因并给「重试」。

### AppSkeleton 骨架
- 静态 `surfaceSubtle` 色块，没有闪光动画；骨架与最终布局同尺寸。
- API：`AppSkeleton({double? width, double height = 14, double radius = 4})`；`AppSkeleton.circle({required double size})`；`AppSkeletonText({int lines = 3, double lineHeight = 14})`
- 整页首屏加载也可用 `AppLoadingIndicator` / `PageInitLoadingShell`（由 `ui.dart` 一并导出）。

### AppAvatar 头像
- 圆形；有图显示图片（网络地址、后端相对路径、`asset:` 引用），没有图或加载失败显示姓氏（名字第一个字，英文取首字母大写），底色按名字在 6 个浅色中固定取一个，字色为同色深色。
- API：`AppAvatar({required String name, String url = '', double size = 40})`；`AppAvatar.initialOf(name)` / `colorOf(name)`
- 不要：用学校 logo 或班级 logo 冒充老师头像。

### AppImage 图片
- 统一处理网络地址、后端相对路径（`MediaUrl.resolve`）、打包资源（`assets/...`）与演示数据引用（`asset:assets/...`，直接按打包资源加载）；加载中浅灰占位，失败显示裂图图标，加载完成直接显示，不做淡入。
- API：`AppImage({required String src, double? width, double? height, BoxFit fit = BoxFit.cover, Alignment alignment = Alignment.center, BorderRadius? borderRadius, Widget? placeholder, Widget? error})`

### AppStatTile 指标
- `caption12` 标签 + Manrope 24 数字 + 单位 + 变化量（变好绿色 ↑、变差红色 ↓，0 不显示）；`invertDelta` 用于名次等越小越好的指标；`boxed` 时带浅灰底，适合横排。
- API：`AppStatTile({required String label, required String value, String? unit, num? delta, String deltaSuffix = '', bool invertDelta = false, Color valueColor = ink, bool boxed = false})`

### AppProgressBar 进度条
- 静态，没有入场动画；胶囊形，轨道 `line`；`striped` 时填充部分叠 45° 白色斜纹（与机构端首页一致），完成可换 `success`。
- API：`AppProgressBar({required double? value, double height = 8, Color color = brand, Color trackColor = line, bool striped = false})`

### AppSteps 步骤条
- 横向多步流程（如人脸库录入「选择人员 → 采集人脸 → 确认提交」）：24 序号圆 + 2–6 字短标签，步骤之间 1px 连线；已完成显示对勾、当前步骤品牌色、之后中性色。切换步骤没有动画。
- API：`AppSteps({required List<String> labels, int current = 0})`；`current` 大于等于步骤数表示全部完成。

### AppCourseCard 课程卡
- 首页课程、课堂签到、任课老师今日课表共用，高度随内容（单节约 122）：
  - 第一行：起止时间（Barlow 18）+ 右侧状态（进行中 brand / 待开始 warning / 已结束 neutral，或自定义 `statusTag`）；
  - 第二行：科目标签 + 大课 / 小课标签（`Wrap`，窄卡片换行，不截断）；
  - 第三行：头像（默认 36，姓氏兜底）+ 名字 + 副标题（时长 · 班级 · 教室）。
- 浅灰子卡片（放在白色面板里）；`selected` 时浅紫底 + 品牌紫描边；已结束时科目与大小课标签转灰。
- API：`AppCourseCard({required String startTime, required String endTime, required String subject, required String teacherName, String subtitle = '', bool isSmallCourse = false, AppCourseStatus status = upcoming, Widget? statusTag, String avatarUrl = '', Widget? avatar, Color? classKindDotColor, bool selected = false, VoidCallback? onTap})`；`AppCourseCard.avatarSize = 36`
- `DashboardCourseNoticeCard` 保留原构造函数，内部渲染 `AppCourseCard`；父级不要再给课程卡固定高度。

## 5. 页面布局模式

所有页面在外壳内容区（`#EFF3FC` 底）上排版，页面左右版心 20，卡片之间 16。

1. **模块首页**使用外壳的白色底板。顶部按需放置返回、操作和筛选，下方用内容卡和分区标题组织信息。指标行用 `AppStatTile(boxed: true)` 等分。
2. **列表页**：页头 → 筛选条（左侧分段 / 胶囊，右侧搜索与「共 N 条」）→ 白卡内的 `AppListRow` 列表或网格；首屏加载用骨架或 `PageInitLoadingShell`，没有数据用 `AppEmptyState`，失败用 `AppErrorState`。分页或加载更多放在列表末尾。
3. **详情页**：页头带返回（`onBack`）、标题为对象名称、副标题为关键属性（科目 · 日期 · 班级）→ 左主右辅两栏（宽 ≥ 760 时 1fr + 320），窄时上下堆叠。主操作在页头右侧或底部固定条，二者只选一处。
4. **弹窗 / 抽屉**：简短确认、单字段输入用 `AppDialog`；名单、选择、筛选、详情和多字段表单用 `AppDrawer`。会改变阶段或不可撤销的操作必须先确认。浮层里只用组件库组件。
5. **1180×820 适配**：外壳内容区约 950 宽。行内用 `Expanded` / `Flexible` 分配宽度，文字设 `maxLines` + 省略；标签用 `Wrap`；不给卡片固定高度，需要对齐时用 `IntrinsicHeight` 或固定的骨架尺寸。

## 6. 加载、空与错误

| 状态 | 做法 |
| --- | --- |
| 首次加载 | 骨架（`AppSkeleton` / `AppSkeletonText`）与最终布局同尺寸；整页可用 `PageInitLoadingShell`。不加闪光。 |
| 局部刷新 | 保留旧数据，不清空页面；按钮用 `loading`。 |
| 空 | `AppEmptyState`：图标 + 标题（这里会有什么）+ 说明（怎么让它出现）+ 至多一个操作。筛选后为空时操作为「清除筛选」。 |
| 错误 | `AppErrorState`：标题说明失败了什么，说明写原因或可做的事，按钮「重试」。有旧数据时用轻提示，不替换内容。 |
| 操作结果 | `AppToast`：成功、失败、信息三种，一句话说明结果。 |

## 7. 文案

- 中文标点：「」『』，。、；：？（），不用英文引号和英文括号。
- 中文与数字之间加一个半角空格（「共 12 件」「第 3 名」「180 分钟」）；接口原样返回的文字不强行改写。
- 数字、分数、日期、计数用 Manrope（`AppText.number`），单位用中文样式。
- 不用感叹号；不用「哦」「啦」等口语词。按钮用动词短语（「上传作品」「开始点评」）；只有确认弹窗的确认键用「确定」。
- 状态词固定：进行中 / 待开始 / 已结束 / 已完成 / 需处理 / 未开始 / 待点评 / 已点评 / 阅卷中 / 已出分。
- 演示数据持续标注「演示数据」「模拟数据」。
- 最小字号 12，任何场景（角标、图例、水印说明）都不例外。
