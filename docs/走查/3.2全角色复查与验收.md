## 本轮发现与修复

| 问题 | 修复与验证依据 |
| --- | --- |
| 教师学生/关注名单只有展示，缺少处理结果 | 增加筛选与跟进抽屉、历史和状态回读；写入 DemoStore，教师限所带班级、校长按校内范围；状态不自动抹去作品风险。测试覆盖权限和重置。 |
| 学生档案抽屉内列表布局及分项口径不完整 | 移除无界嵌套滚动；分项显示 5 级尺度、作品/点评数、区间和同作品多师均值规则，缺样本明确说明。 |
| 定时通知编辑入口只提示不可用 | 复用原保存接口更新同 id；阻止无权限、已发布与不存在记录；填写内容的输入框和关闭按钮补充语义。 |
| 平台不支持售后后，买家订单看不到结论 | 增加订单 dispute 状态与处理卡片，两种处理结果均回写订单事件；处理中禁止重开覆盖，防止重复升级。 |
| 范画赏析入口未开放、练习卡语义重名 | 赏析进入实际范画库；练习卡按自己的类型命名，避免辅助操作误入顺序练习。 |
| 模考旧入口仅有占位 | `/mock` 接入现有学情中心；断言以实际的完整报告入口为准。 |
| 保存二维码文案与能力不符 | 改为保存文件；iPad/移动端向系统文件选择器传入字节，桌面按选定路径写入。原生交互尚待真机验证。 |
| 收藏书刊展示尚不可用的分享项 | 隐藏不支持的分享操作，保留阅读与取消收藏。 |
| 组长首页今日 0 节却呈现未来课程 | 保留 nextSchoolCourse 的未来课程语义，明确“今日暂无排课”及“下一次课程 · 实际日期”；周条保留当天真实数量。固定到无课的周日进行回归，避免日期变化掩盖问题。 |
