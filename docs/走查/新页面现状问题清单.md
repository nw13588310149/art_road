# 新页面现状问题清单

记录日期：2026-11-18。范围：九组美术新增页面改版前的样子。这是 UI 伙伴重构每一页的起点：动手前看这一页的那一节，改完对照一遍。

## 怎么得到的

- 用 `tool/qa/page_preview_test.dart` 把每个页面按身份渲染成整屏图，1180×820 和 1024×768 各 65 张。图在 `build/qa/preview/baseline/`，不入库，可以用 `"--dart-define=LABEL=baseline"` 重新渲染。
- 七组页面分头评审，每组逐张看图，按「整体、主次、节奏、细节」写出问题。这同时是 UI 伙伴技能的一次试跑。
- 标「代码推断」的条目不是从图上看到的。尺寸是在图上量的近似值。
- 评审之后，主笔又亲眼核对了这些屏：今日（学生）、电子书刊（书库、书架）、素材中心（列表、详情）、集市和小课件的列表、学情（学生总览、原卷查看、校长首屏）、作品（学生档案、详情、点评工作台）、工具箱首页和明度检查。其余以评审看图的结论为准。
- 没有看到的部分列在文末。

## 所有新页面共有的问题

### 1. 同一件事有好几种做法

| 事 | 现在的做法 |
| --- | --- |
| 页面底板 | 今日和校长首屏是浅色页面底上放白卡片；其余是一整块白色底板，里面再放描边卡片或灰底卡片 |
| 页头 | 今日是渐变头图；集市、小课件是 24 号标题加副标题加按钮；书刊、素材中心、学情、作品、工具箱首页没有可见标题；各详情页是返回加居中的小标题 |
| 切换视图 | 白色滑块的分段（书刊、工具箱）；放大加粗的文字页签（素材中心）；紫色实底的分段（集市、小课件、今日、作品）；下划线页签（校长首屏）；按钮（学情的「作品成长」「成长曲线」） |
| 筛选项的选中 | 深蓝实底（书刊、素材中心）；紫色描边加浅紫底（集市、小课件、作品墙、校长首屏）；黑底白字（工具面板） |
| 按科目筛选 | 胶囊、文字页签、下拉框、分段控件四种都有 |
| 搜索框 | 宽度从 190 到 324 不等，有时在排序左边有时在右边；页内搜索和顶栏搜索上下相距不到 60 |
| 主按钮 | 紫色渐变和深紫黑两种颜色（书刊「开始阅读」、工具箱「去使用」是深色）；位置有右上角、行中间、右下固定、面板底部、画布里 |
| 列表卡片 | 浅紫底无描边（书刊网格）；浅灰底无描边（素材中心、工具箱、作品墙）；白底描边（集市、小课件、学情、作品档案）；通栏的行（复核池、点评链） |
| 状态标签 | 压在图上的角标、方角小标签、圆角胶囊三种形状；同是「待点评」，学生看到橙色，老师看到琥珀色 |
| 收藏 | 图标有星形、书签、心形；叫法有「收藏」「加入书架」 |
| 概要数字 | 灰底块、灰色小胶囊、大号数字加竖线、带彩色图标底座的数字卡 |
| 图表读数 | 只标最后一点、每点画圆不标数、柱子要点按才出数、柱顶直接标数 |
| 空状态 | 居中的图标加标题加说明；卡片里左对齐的一句话 |
| 提示与声明 | 顶部琥珀色通栏、右栏底部琥珀色块、灰色说明块、一行灰字 |

### 2. 看不出自己在哪一页

- 书刊、素材中心、学情、作品各屏、工具箱首页都没有可见标题。组件库的 `AppPageHeader` 按设计只把标题交给读屏，不画出来。
- 名称对不上：
  - 导航「优秀课件」，页内标题「小课件」，页签「发现专题」。
  - 导航「素材中心」，页内一律说「范画」。
  - 首页入口「作业」「作品墙」，页内是「作品档案」「优秀作品墙」「复核池」。
  - 校长首屏的入口「班级学情」，点进去标题是「全校学情」。
  - 文档里的「教学报告」在界面上叫「教学报表」。
- 集市、作品、工具箱、教学报告各页，以及学生的学情，打开后左导航没有高亮项。

### 3. 摘要挤走正文

- 今日：第一条待办在 1180×820 下从屏高 73% 处开始，1024×768 下是 83%。上面是头图和四张数字卡。
- 作品档案：作品图从内容区三分之二处才开始，上面是三格统计和「点评小结」。
- 学生总览：成绩卡占首屏近一半，其中约四成是和这场考试无关的历史场次。
- 点评工作台：流程卡排在表单前面，评语输入框在首屏以外，每点评一份都要先滚动。
- 学生的作品详情：首屏没有一句老师的评语，先看到的是流程卡。
- 班级学情：学生列表排在第五块，两种尺寸的首屏都看不到。
- 电子书刊：封面网格从屏高 46% 处才开始。

### 4. 颜色

- 品牌紫过多：今日学生首屏约十一处，成绩报告超过十处，学生总览七处，校长首屏五处。紫色已经指不出重点。
- 大面积的紫：今日的渐变头图约 970×196；班级学情两张图表的实心紫柱和整片浅紫。
- 没有含义的彩色：今日的图标底座有紫、粉、青、琥珀、蓝五种，同一件事在不同位置颜色还不同；姓氏头像每人一种底色。
- 一色多义：绿色同时表示「已点评」「色彩」科目、「进步」和书刊的「基础」阶段；蓝色同时表示「素描」和「提高」。
- 状态色帮倒忙：今日里已完成的部分用红色填充，越接近完成红色越长；一件超时的事在首屏用了六到八处红色；校区均分低 1.7 分就标红。
- 第三种深色：书刊和工具箱的深紫黑按钮，在首页和其他新页面都没有出现过。

### 5. 容器与留白

- 层层嵌套：白色底板、描边卡片、灰底块、图标底座，常见三到四层（学情、作品档案的统计区、今日清单、工具箱首页）。
- 留白不在分组：工具箱「练习训练」「备考助手」下方四分之三是空的；书架下半屏是空的，卡片里却挤着五样东西；老师履职的表格只占卡片四分之三宽；专题详情三张通栏卡片右半边是空的。
- 同一模块里页边距、卡片间距、页头到正文的距离不一致，切换视图时内容上下左右跳动（学情五屏有四种起始高度）。

### 6. 作品图被裁、被压

- 集市把作品裁成固定高度的横条，竖幅作品的头和脚被裁掉。
- 作品档案、优秀作品墙、校长首屏的「近期作品」都按固定比例裁切，有的人物头部被裁掉。
- 工具箱的示例缩略图和速写参考图裁成正方形，速写练的是完整动态，预览里看不到完整的人。
- 书刊封面上最多叠了三个标签（阶段、收藏星标、阅读进度），盖住封面自己印的书名和编者。
- 作品档案的缩略图上有状态角标、「复核中」、「2 张」三处遮挡。
- 书刊网格里封面衬在浅紫底上。

### 7. 字太小、太淡、被截断

- 要读的信息是最淡的字：工具卡的说明（代码推断：11 号、占位灰，对比度约 1.9:1）、书刊的编者和阅读进度、小课件的难度和时长、集市的库存。
- 不在规定字号里的字：11 号（书刊、工具箱）、10 号（素材中心）、15 号（详情页头标题）、18 号（文字页签的选中项）。代码推断。
- 截断：书库第一行五个书名全部被截；书架在 1180×820 下两期月刊显示成同样的「画室月刊 2026 年 1…」；今日在 1024×768 下七处说明被截，截掉的常是时间和数量；作品墙每张卡片的分数被截掉。
- 被压住：书架卡片上「读到第 5 / 12 页」的「页」被按钮压住；人体比例图上「1 头长」被标尺线穿过。

### 8. 点击目标偏小

可见尺寸普遍小于 44：返回按钮约 32，筛选胶囊约 30，小按钮约 34，收藏图标约 28 到 34，勾选框 16，今日时间线上的圆圈约 34。收藏图标和行内按钮还压在整张可点的卡片上，点偏了会进详情。点击区域是否另有扩大需要读代码确认。

## 逐页

### 今日（`/today`，七种身份）

镜头：`today`。

最要紧的：

1. 清单被头图和数字卡挤到首屏底部，首屏只能看全一到两条待办。
2. 头图里的「下一步」在清单第一行又出现一次，各带一个文字相同的紫色主按钮。管理员屏更糟：头图说的那件事在清单首屏找不到。
3. 同一个数反复出现：学生屏的「11」有六处；四张数字卡基本都在重复清单和右栏图表里已有的内容。
4. 一件超时的事用六到八处红色，早上八点打开就是报警的样子。
5. 清单每行一个按钮（学生 11 行就是 11 个），加上整行可点、圆圈可打勾，一行三个点击目标，外观上看不出差别。

其他：

- 右栏第一张卡「近 7 天完成」把刚开始的今天也算进完成率，早上看总是偏低；它排在和今天直接相关的卡片前面。
- 数字卡右边有的画环、有的画小柱、有的空着；环的颜色跟图标走，不跟好坏走（「未打卡 4 人」旁是九成满的粉红环）。
- 时间线上可以打勾的圆圈和不能打勾的只差一点灰度，提示条只说「点一下圆圈打勾」。
- 页面很长：学生页在 1180×1800 下还没到底，右栏比左栏短约两百像素。
- 时间段有三种写法，和首页课表的写法是第四种；同样三节课，首页和今日长得不一样。
- 可点控件偏小：头图刷新按钮 28，圆圈 34，按钮高 34。

### 电子书刊（`/ebooks`）

镜头：`ebooks`、`ebooks-shelf`、`ebook-detail`。

最要紧的：

1. 书名全部被截断，而封面上已经印着同一个书名；截掉的正是用来区分的部分。
2. 封面上叠着阶段、收藏、进度三个标签，盖住封面自己的标题（「冲刺」盖掉「画室月刊」的「画」）。
3. 「编辑推荐」的三本和「全部书刊」的前三本是同样三本，首屏八个书位里三个是重复的。
4. 书架把没开始读的排在最前面，在读的排第三第四；五张卡片五枚一样的深色按钮。
5. 详情页右栏三张「相关书刊」的彩色封面比主封面加起来更大更艳，先于阅读按钮被看到；书名是全页最弱的标题。

其他：

- 网格里封面衬在浅紫底上；上半屏有深蓝、深紫黑、蓝绿紫三组深色小块和封面抢注意力。
- 正在读的那本没有被单独对待；同一本书在推荐条里能直接读，在网格里只能先进详情。
- 详情页六行键值信息一样重，「出版」「发布日期」和「适用阶段」平起平坐；目录被压到屏高 75% 以下；目录里读到的那一章没有标记。
- 「示例」在详情首屏至少出现六次。
- 1024×768 下分类胶囊最后一个「期刊」看不到，也没有可以横滑的提示。
- 阅读进度有四种表达；「书架」在两屏含义不同。

### 素材中心（`/gallery`）

镜头：`gallery`、`gallery-detail`、`gallery-compare`。

列表的大关系是对的，画按原比例显示，是主体。问题在控件和小元素：

- 全页最大的字是选中的科目页签「全部科目」，看上去像页面标题，其实是筛选值。它正下方又是一个深蓝的「全部」。
- 卡片信息行里浏览量比作者更大更清楚（代码推断：10 号对 12 号）。
- 每张画右上角一个白底星标压在画面上，在白纸素描上几乎看不见。
- 来源放在两处：学生作品是图上的绿色标签，名师范画是信息行里的文字。
- 详情页右栏先是作者卡，「点评要点」在后；最能直接用的「临摹建议」没有标题，藏在「作品说明」的第二段。
- 详情页变窄时只压缩画布，右栏始终 320 宽。
- 对比页两张画显示比例不可比，一张按高撑满一张按宽撑满；全屏唯一的颜色是两枚紫色的查看方式开关。

### 优秀课件（`/micro-lessons`）

镜头：`topics`、`topic-detail`、`topic-new`。

最要紧的：

1. 卡片上半是书的封面，而且常是同一张封面放两次，看上去像书库，看不出放的是知识点专题。专题标题排在封面下面，最后才被看到。
2. 第一眼落在「新增小课件」，学生来这一页主要是找内容读。
3. 首屏只能看全一排，1024×768 下只有两个专题。
4. 三个叫法：优秀课件、小课件、专题。

其他：

- 详情页有两个 24 号标题，页头的「阅读专题」只说明页面类型却排在上面；同一张封面在首屏出现两次；三张卡片的左边缘有三条线。
- 新增页左右两栏各自滚动；两个下拉框没有字段名；必填和可选的标法不统一；示例书籍占的面积比上传按钮大得多；勾选框只有 16 见方。
- 封面图上印的是「美术之路 · 示例书刊」，产品名已经是「美育集」。

### 集市（`/market`）

镜头：`market`、`market-detail`、`market-new`、`market-orders`、`market-seller`、`market-moderation`。

最要紧的：

1. 作品图上方有四行控件，第一张作品从内容区三分之一处才开始；页头并排三个 45 高的按钮，最重的位置给了卖家的事。
2. 作品图被裁成横条，竖幅作品的头和脚被裁掉。
3. 1024×768 下详情页的「购买使用许可」只露出上半截；作品底板上下各空出一百多像素，右栏却放不下。
4. 页签「发现作品 / 数字授权 / 实物作品 / 创作分享」不是并列关系；第三种在页签上叫「创作分享」，卡片上叫「仅展示」。
5. 两个编辑页左右相反：小课件是表单在左、材料在右，集市是选图在左、表单在右。

其他：

- 页签的灰色轨道被拉成通栏，右边是一长条空的灰底。
- 详情页价格和它对应的授权名称之间隔着三段文字；一栏里用了七种字号字重；「演示」提示有四种措辞。
- 发布页的权利声明在表单最末，1024×768 下在首屏以外，而「提交审核」在页头。
- 订单空状态写「暂无匹配的订单」，可当前并没有筛选；六个状态胶囊照常显示。
- 工作台里「下架」和「查看作品」是两个一样的小按钮，紧挨着；价格埋在灰色说明行末尾。
- 审核页两个队列都空时是两个同样分量的空框，要读两遍才确认没事。

### 学情：学生与教职（`/study`）

镜头：`study`、`study-report`、`study-paper`、`study-growth-exam`、`study-growth-artwork`。

最要紧的：

1. 学生总览的成绩卡占首屏近一半，「各科表现」被压到下半屏；「看原卷」「评分标准」在每张科目卡最底部，首屏看不到（代码推断）。
2. 「成长曲线」是全屏唯一的紫色实心按钮，却只是换个视图；真正接着往下看的「查看完整报告」是浅紫底小按钮，和旁边的标签分不清。
3. 成绩报告的上面近四成是总览里那张成绩卡，一字不差；表格里六个紫色链接是最重的东西。
4. 三科用三种科目色写大数字，加上紫色分数环，首屏四团颜色分不出主体。
5. 班级学情首屏全是汇总，学生列表在第五块；导航叫「班级学情」，数字却是全画室的，班主任看不到「我的班」。

其他：

- 成绩报告在 1180×820 下两列名次粘在一起，读成「第 11 名 / 38 人第 5 名 / 13 人」。
- 成长曲线横轴标签被截成「暑期集训…」（代码推断：考试名超过 6 个字一律截短）；纵轴从 230 起并铺了面积，把涨幅放大了；「265.5」在首屏出现四次。
- 作品成长里左栏四条进度条几乎一样长（4.2 到 4.7），右栏却把其中两项列为要继续练的问题；落点「下一次练习」和唯一的主按钮在首屏最底下。
- 原卷页底色偏蓝紫（量到 #0B081A），色彩卷放在上面会影响冷暖判断；底部五个档位胶囊像可点的筛选项，实际只是图例。
- 原卷上的水印「林小雨 A260001 · 仅供本人学习」斜着铺满整张卷子，几十处，字是清楚可读的，看画时一直在干扰。
- 班级学情六个灰块一样重，「满分 300 分」是常量却占一格；校区对比三条进度条几乎一样长。
- 学情的版心：作品成长用四边 16，其余几屏左右 20（代码推断）。

### 全校学情与教学报告（校长的 `/study`，`/teaching-overview`）

镜头：`study`（校长）、`report-classes`、`report-review-chain`、`report-teachers`、`report-attention` 等。

## 做得好、应当保留的

- **图片为主的几屏**：素材中心列表按原比例显示画；集市卡片图大、卡片上没有按钮；作品详情和工具画布完整显示作品，底色接近中性。
- **校长首屏**：一屏放完不用滚动；大数字各带一句对比口径；报表行是「名称、说明、当前数、箭头」，整行是入口；图表只用一种颜色，从 0 起算。
- **今日**：时间线的骨架（左边时间、中间一条线串起状态、按时段分组、带「现在」线）；每个身份算出一件「下一步」；七个身份同一副骨架；每行说明写清来源和原因。
- **学情**：分数环让第一眼落在总分上；数字带分母和单位；成长曲线每个点直接标数；口径说明写得具体克制。
- **作品**：点评小结的内容具体，问题和亮点分开、带次数；工作台大图和表单左右分栏，保存按钮固定在底部；「原图 / 老师批注」切换就在大图上方。
- **优秀课件与集市**：都用组件库搭建，字号在规定范围内；主按钮固定在页头右上；授权条款用平实的话写清楚；演示交易有明确标注。
- **工具箱**：面板选项等高等宽，当前值一眼可辨；网格线压在明暗不同的画面上都看得清；倒计时只有最近一场用紫色。
- **通用**：状态都带文字；科目色和首页一致；文案平实，用中文标点，没有感叹号和承诺用语；两种尺寸下都没有版式警告。
