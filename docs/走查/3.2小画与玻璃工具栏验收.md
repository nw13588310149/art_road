# 3.2 小画与玻璃工具栏验收

日期：2026-11-15。范围为全局美术工具入口及其相关首页、工具交互回归；本轮不调整版本号、Bundle ID 或签名。

## 实现与设计边界

沿用 [设计规范](../设计规范.md) 和 [3.1 产品与交互方案](../美育集3.1产品与交互方案.md)。小画承担友好入口，专业工具减少对画面的遮挡；操作顺序为“小画 → 工具列 → 参数或精确操作 → 小画”。这是既有浅色横屏界面的扩展，不另建设计系统。

- 收起态复用原向量小画，外框为 64 点，贴边休息仍保留至少 44 点触控目标。保留眨眼、张望、蘸色、涂鸦和拖动反馈，遵循已保存的动态偏好及系统减少动态设置；隐藏或后台时停止动画。工具列没有新增动态开关入口。
- 点击小画展开 52 点单列工具栏，按钮热区为 44 点；点击顶部握柄收回小画。小画可四边停靠，展开后的工具栏拖动仅靠左右两边。展开与收起不改写持久停靠位置。
- 工具栏采用 16 点圆角玻璃背景，按钮仍用既有 `AppPressable`；品牌紫选中态即时切换，图标按钮有语义名称与提示。用户明确允许小画与材质动画，此例外不改变其他控件的动效规则。
- 参数面板沿用既有文字样式和操作。关闭参数保留效果，结束工具清除效果；取色、测量让出画面，退出精确操作可返回工具列。完整工具箱、笔记编辑和业务弹层继续让出操作区域。
- 没有新增依赖或图片资产，共用左导航、顶栏和既有参考页面保持原实现。

实现位置：`lib/features/art_toolbox/ui/floating_toolbox_host.dart`、`widgets/professional_tool_rail.dart`、`widgets/tool_glass_surface.dart`、`widgets/toolbox_companion.dart`；原生背景在 `ios/Runner/ArtToolGlass.swift`，注册入口在 `SceneDelegate.swift`。

## 原生材质与回退

iOS 通过 `UiKitView` 承载 `UIVisualEffectView` 背景，工具按钮、焦点、无障碍语义和业务状态仍由 Flutter 管理。平台视图接入方式参见 [Flutter iOS platform views](https://docs.flutter.dev/platform-integration/ios/platform-views)。

使用 Xcode 26（Swift 6.2、iOS 26 SDK）或更新工具链编译、且运行在 iOS 26 或更新系统时，背景使用 [`UIGlassEffect`](https://developer.apple.com/documentation/uikit/uiglasseffect)。源码保留 `#if compiler(>=6.2)` 与运行时版本检查；旧工具链分支或旧系统使用 `UIBlurEffect`。本机未编译这些原生分支。

原生背景关闭自身命中，Flutter 通过 pointer down / up / cancel 转发接触状态，驱动 180ms 材质反馈；这不等同于已实现或验证系统玻璃的完整触摸形变。系统减少动态时取消过渡，减少透明度或增强对比时改为不透明背景。Web 和原生桥尚未就绪时使用 Flutter 模糊兼容材质，高对比时为不透明白底。
