## 1. 按身份的首页

区块由 `home/state/home_sections.dart` 的 `homeSectionsFor(role)` 决定，`/myInfo` 回包前演示版按登录 token 还原身份，避免先闪出别的身份的卡片。版式：上方左栏（轮播 + 功能入口 + 三科入口）与右栏（课程或今日待办）等高；第二行左卡与左栏同宽、右卡与右栏同宽，同一行等高（`IntrinsicHeight`），1180×820 下各身份测试检查无溢出、等高。

| 身份 | 右栏 | 第二行 | 其他 |
| --- | --- | --- | --- |
| 学生 | 今日课程 | 今日练习 + 最近点评 | 学情速览、精选书刊 / 继续阅读、资讯 |
| 任课老师 | 今日课程 | 画室学情速览 + 作品点评（待点评 N 件） | |
| 班主任 | 今日课程 | 画室学情速览 + 今日待办 | |
| 管理员 | 今日待办（替换原来空着的课程卡） | 画室学情速览 | |
| 宿管 | 今日待办（替换「今日值班」） | — | 不显示学情、课程与三科范画入口，功能入口排成 4 × 2 |

- 今日练习（`home_practice_card.dart`，数据 `homePracticeProvider`）：取 `GET /app/artworks/insights` 的高频问题（最多 2 条），问题对应的工具用 `ArtTool.tryParse` 换成工具箱 key 直达（如「结构错误」→ `{'tool': 'mirror'}`），没有工具时打开范画库对应科目 + 关键词；再补最近一次已出分考试分数最低的一科（「2026 年 9 月月考色彩 85 分（B 档）…」→ 范画库 `{'subject': '色彩'}`），没有考试时用日常作品的「有待加强」；什么数据都没有时给「明度排序训练」「人体比例参考」两项基本功。逻辑在 `buildHomePractices`。
- 最近点评（`home_latest_review_card.dart`）：已点评作品取第一份，再取详情拿评语；显示封面、科目、绘画日期、最终得分（品牌色）和最近一位写了评语的老师的第一句（演示数据为「李静：结构交代清楚，暗部再整体一些」，与铃铛消息同一句），点开 `RoutePaths.artworks {'artworkId'}`。
- 待点评 N 件（`home_review_queue_card.dart`）：`GET /school/teacher/artworks/statistics`（阅卷客户端），「开始点评」进入作品点评（默认显示待我点评），返回首页后刷新件数。
- 今日待办（`home_todo_card.dart`，行由 `buildHomeTodos` 生成）：班主任为待点评作品 / 班级工作台 / 未读消息；宿管为晚查寝、早查寝（学校作息配置）/ 到岗打卡 / 宿管请假 / 未读消息 +「按宿舍查寝」；管理员为教师请假审批、小课签课确认（与智慧校园管理员首页同一接口 `indexSum` 的两个数）/ 排课与课表 / 未读消息 +「进入智慧校园」。每行点开智慧校园对应视图；「未读消息」打开通知抽屉。
- 同步智慧校园的命名：宿管入口「打卡管理」→「到岗打卡」（T-150 的共享文件请求），管理员入口「宿管请假审批」→「教师请假审批」（与智慧校园页面标题一致）。
- 「继续阅读」沿用 `HomeEbookShelfSection`，未改。

## 2. 点开即跳转的通知

- 消息带 `targetType` + `targetId`，映射在 `shell/navigation/shell_notice_routes.dart`：1 学情 → `/study {examId}`，2 作品 → `/artworks {artworkId}`，4 书刊 → `/ebooks {bookId}`，5 校园 → `/smart-campus`，6 工具上新 → `/toolbox {tool}`，3 系统通知没有目标页。
- 抽屉（`shell_notice_drawer.dart`）：未读消息带红点、已读置灰，可跳转的行带箭头；点一条会关闭抽屉、标为已读（`ShellController.markNoticeRead`，先改本地、接口失败由下一次轮询纠正）并把目标页压栈打开（返回回到原页面，会员失效时只提示）。「全部标为已读」只在有未读时出现，已读消息仍保留在列表里。
- 演示数据（`platform_core_fixtures.dart`，存储键升级为 `notices:v2:`）：学生——李静点评《石膏头像结构练习》（作品 id 从作品演示数据里查，时间为最后一位老师点评后 2 分钟 11-06 09:12）、9 月月考（examId 26）原卷上线、班级通知提醒、工具箱上新（综合分计算器）、书刊上新（最新上架的《画室月刊 2026 年 11 月号（示例）》，11-01）；老师 / 班主任——最近提交、自己还没点评的作品 +「你还有 N 件作品待点评」（N 与点评统计接口一致）；宿管——「今晚 22:10 晚查寝」（与学校作息配置同一常量）；管理员——审批与签课提醒。没有对应事件的消息用 `DemoClock` 往前推，均不晚于演示当前时刻。`/app/msg/list` 返回含已读的全部消息（新的在前），`/app/msg/updateRead` 按 `ids` 只标指定消息，不传时全部标为已读。

## 4. 新手引导

- 内容 `help_guide/data/role_guides.dart`，每个身份 3–4 步，指向该身份真实可见的入口：学生 我的学情 → 作品档案 → 画室工具箱 → 美术书刊；任课老师 作品点评 → 班级学情 → 智慧校园；班主任 班级工作台 → 班级学情 → 作品点评 → 今日待办；宿管 今日待办 → 按宿舍查寝 → 到岗打卡 → 宿管请假；管理员 教务管理 → 审批与签课 → 通知管理 → 班级学情。
- 弹窗 `help_guide/ui/role_guide_dialog.dart`：只有弹窗本身淡入，换步立即切换；「跳过 / 下一步」，最后一步「开始使用」。「跳过」是普通按钮，读屏名称就是「跳过」。
- 触发：`ShellScaffold` 在首页、`/myInfo` 拿到身份、会员有效、没有其他弹窗开着时调用 `RoleGuideLauncher.maybeShow`；「已看过」按身份存在 SharedPreferences（`role_guide_seen_v1:<role>`），弹出即记为已看过，刷新页面不会再弹。
- 帮助页：页头「新手引导」随时按当前身份重新打开；演示版在页头下方有提示条「跳过新手引导 / 恢复新手引导」（一次处理全部身份）。
- 截图走查：每个身份第一次打开首页会弹引导。只想截首页本身时，`tool/qa/pages.mjs` 的 home 步骤加一个 `'跳过'` 点击，或先打开 `/help-guide` 点「跳过新手引导」。

## 5. 综合分预估（我的学情）

- 卡片 `study_center/ui/widgets/study_composite_estimate_card.dart`，放在表现解读与考试记录之间。专业成绩取最近一次已出分考试的总分（林小雨 9 月月考 265.5 / 300，满分不是 300 时按比例折算），文化课预估分与目标综合分由学生填写，省份预设甘肃（可选安徽、北京、福建、黑龙江、云南），用画室工具箱现成的 `scoreRuleFor` + `computeScore` 计算，显示公式与计算过程。
- 结果用品牌色大号数字；填了目标分时显示「距目标还差 N 分」（提醒色）或「已达到目标，高出 N 分」（成功色）。始终显示「仅供参考，以当年省教育考试院公布为准」，页头右侧「完整计算器」打开 `/toolbox {'tool': 'score'}`。没有已出分的考试时只显示说明与入口。
- 输入按账号（手机号）存在本机（`study_composite_estimate_v1:<手机号>`），下次打开回填。计算与存储在 `study_center/data/composite_estimate.dart`。
