# 音乐之路界面对照

对照版本为音乐之路 `80e9dd3c`。以 1180×820 横屏为基准。美术之路沿用艺考网标识、品牌紫 `#715EFE`、美术素材及现有业务数据。旧版截图使用本地测试数据，因此页面内容量会与美术之路演示版不同。

后续统一调整由外壳提供白色内容底板，页头只留返回、操作和筛选控件。下表记录的是首次对照时的版式，页头标题和副标题以最新的《设计规范》为准。

## 智慧校园

五类身份首页对照各自看板。二级页按入口匹配页头、统计卡、返回、筛选和操作区。统计卡恢复右侧通用插图，页面保持原有业务表单和状态。

| 身份 | 对照入口 |
| --- | --- |
| 学生 | 我的班级、我的课表、课堂签到、我的作业、我的考试、群聊、校圈、我的请假、我的查寝、校长信箱 |
| 任课老师 | 授课课表、签课管理、作业批改、考评管理、学生名册、我的请假、校圈、群聊、校长信箱 |
| 班主任 | 班级工作台、请假审批、家校沟通、查寝历史、群聊、校长信箱 |
| 宿管 | 按宿舍查寝、查寝动态、查寝历史、到岗打卡（旧版「打卡管理」）、宿管请假、校圈、群聊、校长信箱 |
| 管理员 | 学生管理、教师管理、班级管理（旧版「班级编辑」）、排课与课表、签课管理、请假审批、人脸库、通知管理、群聊、校圈、校长信箱 |
