# 小画：当前页面画具抽屉

2026-11-12。将小画的悬浮卡片改为右侧通高抽屉。常用工具在业务页面上直接生效，底部「进入完整工具箱」才打开原有 17 个工具的完整工作台。

- 抽屉宽度上限 360，内容滚动，关闭按钮和完整工具箱入口固定；不压缩或重排原页面。
- 构图网格：九宫格、4×4、6×6，深浅线条和强度可调，页面可继续滚动。
- 明度检查：当前页面实时灰度，开关对照原页面，附五阶明度参考。
- 镜像翻转：水平、垂直翻转当前页面，开关对照原页面。
- 比例测量：两条测量线、四个可拖动端点，显示逻辑像素长度、角度及 A/B 比例。不是实物尺寸测量。
- 取色与色卡：从原页面绘制层读取像素，不包含抽屉和精灵；点击取色期间拦截页面动作，支持复制色值和暂存最多六种颜色。读取失败给出可重试提示，读取结果过期时丢弃。
- 速写计时：30 秒、1/2/5 分钟，开始、暂停、重置；收起抽屉后继续计时并显示剩余时间。根据实际截止时间计算，恢复前台后不会因定时器节流延长练习。

「收起抽屉」保留当前工具与参数，页面底部的「调整」「结束当前页面工具」用于重新调参或退出；切换业务路由结束工具，退出登录清空临时状态。一次启用一个工具，避免多个效果叠加导致误读颜色或比例。

玻璃材质使用 Flutter BackdropFilter、半透明表面和边缘高光，Web 与 iPad 使用同一实现；高对比度模式使用不透明底色。不调用或宣称 Apple 原生 UIGlassEffect，不添加依赖。用户明确要求玻璃抽屉，是原有实底面板样式的局部替换。参考页面没有对应的当前页美术工具层。

验证：页面工具控制器测试覆盖计时暂停/恢复/超时、端点范围与色卡去重；界面测试覆盖通高右侧布局、页面原位操作、参数保留、返回/切页/登录清理。浏览器脚本为 `tool/qa/page_tools_drawer.mjs`，检查六种工具与工具箱入口，覆盖五种角色及 1180×820、1024×768、720×400。iPad 真机与原生平台编译需在对应设备验证。
