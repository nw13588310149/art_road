## 通用做法

- 逐文件对比 `git diff --no-index <R 同路径文件> <T 文件>`，版式、尺寸、字号字重、颜色、形状、图片资源、交互以 R 为准；数据绑定、路由、权限、美术文案沿用 T。
- 页头统一用共享横幅 `SmartCampusPageBanner` + 外壳 `SmartCampusSecondaryPageShell`（`bodyTopClipRadius: 8`，不裁掉首行卡片自己的圆角）。原版没有副标题的页面只显示标题。
- 原版各页私有的下拉、页签、方角标签、方头像换成共享组件（`SmartCampusFilterDropdown`、`SmartCampusDarkTabs`、`SmartCampusSquareTag`、`SmartCampusSquareAvatar`）；原版本页独有的部件按 R 的数值写在页面里。
- 颜色恢复原版色值；原版主紫 `#8741FF` 换成 `AppColors.brand`，浅紫 `#A773FF` / `#B68BFF` 换成 `AppColors.brandSoft`，渐变 `#B68EFF→#8640FF` 换成 `brandSoft→brand`。
- 可点元素用 `AppPressable`（没有按压动画）。
- 共享方角标签 `SmartCampusSquareTag` 自带居中对齐，放在有限宽度的父级里会撑满整格；本任务在这类位置外包一层 `Row(mainAxisSize: MainAxisSize.min)`，没有改共享组件。
