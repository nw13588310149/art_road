# 小画：美育集画室小画童

小画是戴着调色盘贝雷帽、握着水粉笔的软糯小画童。身体是一团带高光的品牌紫，帽子上有朱红、暖黄、天蓝三团颜料，笔尖蘸着其中一种。五官、帽子、手臂和笔全部由原生矢量绘制，不增加图片资源或动画依赖。

- 轻点立即打开原有画具面板，继续复用全部 17 个工具与当前画作。面板标题旁是笑着的小画，说明为「小画 · 拖动贴边，轻点展开」。
- 3 秒未操作，贴边露出一半；12 秒后露出约三分之一。五官随边缘向画布内侧移动。
- 贴边休息时每 7 秒轮换一段短表演：眨眼、左右张望、探头挥手、把笔蘸到帽子上的下一种颜料、朝画面里涂一笔爱心 / 星星 / 旋涡。完整露出时，探头和涂鸦改成挥手。贴上沿时帽子在屏幕外，蘸色改为张望。
- 本次会话第一次出现时跳出来挥手问好，并洒一圈颜料星光；之后重新出现只轻轻弹出。点按会笑一下。拖动时被拎起来，身体朝运动方向倾斜，松手后弹回并落地。
- 眼睛会短暂看向画面里刚点过或悬停的位置。拖动时身后留下一笔会收细消失的颜料。
- 不沿边自动游走，不发声，不弹催促消息。
- 拖动时完整露出。鼠标移入时短暂露出全貌并挥手；鼠标静止或拖动松手后，仍按 3 秒 / 12 秒收纳，不需要移开鼠标。键盘聚焦操作时保持完整显示。
- 可见部分缩小时，交互区域仍至少为 44 像素。只捕获靠边的小区域，画布其余部分正常操作。
- 面板的「精灵动态」开关保存在本机；同时遵守系统「减少动态」。关闭动态后收纳仍可用，表情动作与位移动画停止。
- 进入工具全屏、出现业务模态框或应用进入后台时停止角色动画；回到原页面可再次调用。

## 参考与有意差异

[Apple AssistiveTouch](https://support.apple.com/guide/ipad/use-assistivetouch-ipad9a2466d3/ipados) 提供可移动入口与闲置可见度设置，这里借鉴其位置稳定、按需调用的方式。

[Duolingo 角色规范](https://design.duolingo.com/writing/duo) 提倡轻微且有表情的动作，避免突然的快速移动；小画采用间歇短表演和安静开关，没有常驻逐帧循环。

[Duolingo 形状语言](https://blog.duolingo.com/shape-language-duolingos-art-style/) 强调简化形状、视觉节奏与可辨认的性格。小画用原创的调色盘帽子和水粉笔，不复刻参考作品的角色造型。

本次角色动画由用户明确提出，是原有界面即时切换规则的局部扩展；工具参数、其他页面和业务控件的交互节奏保持既有实现。角色形态是美术场景专属内容，原有参考界面没有对应角色。
