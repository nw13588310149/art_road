# 小墨：美育集画具精灵

小墨是一团带笔锋的紫色颜料。圆团对应颜料的体积，顶端的一撮笔锋与画室语境相连。使用既有品牌紫与浅色高光，五官由原生矢量绘制；不增加图片资源或动画依赖。

- 轻点立即打开原有画具面板，继续复用全部 17 个工具与当前画作。
- 3 秒未操作，贴边露出一半；12 秒后露出约三分之一。五官随边缘向画布内侧移动。
- 每 7 秒一次短眨眼，每第三次加入小幅探头；不沿边自动游走，不发声，不弹催促消息。
- 拖动时完整露出并稍微倾斜，松手吸附最近一边；鼠标悬停或键盘聚焦时露出全貌。
- 可见部分缩小时，交互区域仍至少为 44 像素。只捕获靠边的小区域，画布其余部分正常操作。
- 面板的「精灵动态」开关保存在本机；同时遵守系统「减少动态」。关闭动态后收纳仍可用，表情动作与位移动画停止。
- 进入工具全屏、出现业务模态框或应用进入后台时停止角色动画；回到原页面可再次调用。

## 参考与有意差异

[Apple AssistiveTouch](https://support.apple.com/guide/ipad/use-assistivetouch-ipad9a2466d3/ipados) 提供可移动入口与闲置可见度设置，这里借鉴其位置稳定、按需调用的方式。

[Duolingo 角色规范](https://design.duolingo.com/writing/duo) 提倡轻微且有表情的动作，避免突然的快速移动；小墨采用间歇动作和安静开关。

[Duolingo 形状语言](https://blog.duolingo.com/shape-language-duolingos-art-style/) 强调简化形状、视觉节奏与可辨认的性格。小墨采用原创颜料轮廓和笔锋，不复刻参考作品的角色造型。

本次角色动画由用户明确提出，是原有界面即时切换规则的局部扩展；工具参数、其他页面和业务控件的交互节奏保持既有实现。角色形态是美术场景专属内容，原有参考界面没有对应角色。
