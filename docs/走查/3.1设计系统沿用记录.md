# 3.1 设计系统沿用记录

记录日期：2026-11-15。范围：校长教学总览与图表、作品点评摘要、小课件、集市及其新增与阅读页面。本记录是现有体系扩展的交接证据，不建立另一套设计规范。

## 设计依据与写入边界

- 视觉依据仍是 `docs/设计规范.md`、`lib/core/ui/ui.dart` 导出的令牌与组件，以及 `AGENTS.md` 中既有页面优先的约束。产品与流程依据为 `docs/美育集3.1产品与交互方案.md`。
- 扫描时项目根目录不存在 `PRODUCT.md`、`DESIGN.md`。这不表示缺少产品或视觉依据；本轮不创建替代规范，不创建 `.impeccable/design.json`，也不迁移现有令牌。
- 本轮是既有横屏应用中的功能扩展，目的为处理教学事务与阅读资料。继续使用固定侧栏、顶栏、浅色页面底与白色内容卡，保留 ArtEd.Hub / 美育集身份。
- 文档交接仅新增本文件。扫描时 `git diff --name-only -- lib/core/ui lib/features/shell` 没有输出；这一证据只说明这些目录相对当前 Git 基线没有工作区差异。

## 页面组织与业务状态

- 校长页面沿用组件库组合指标、趋势与待办。`teaching_overview_page.dart` 在内容宽度小于 740 时把图表与待办改为上下排列；宽时按 7:4 分栏。折线图对缺失值使用断点，百分比轴以 0–100 为范围，不把缺失值伪装成零。
- 小课件与集市均以页头、筛选、图文网格进入详情。两者在内容宽度 880 处切换三列与两列。这些阈值是页面实现细节，不升级为通用组件库断点。
- `artworks/ui/widgets/artwork_review_summary.dart` 使用同一 `AppCard`、头像、文字与数字样式，按任课老师、教学组长、校长分组显示。人数来自已完成的独立评价记录，底部直接解释教学参考分与校长分的区别；身份与状态不只依靠颜色区分。
- 新专题与集市编辑采用完整页面，表单、资源选择和预览分别组织在卡片内。上传规则为普通可换行正文；它不受单行卡片副标题的省略规则限制。
- 已关联书刊的阅读资料继续调用既有 `EbookReaderPage`；新增图片书使用 `CreativeReadingController` 管理页码、范围及串行保存。仓库接口在 `creative_hub/data/creative_repository.dart`，演示记录在 `lib/core/demo/fixtures/creative_hub_fixtures.dart`；用户阅读进度不存放在页面静态字段中。
- 小课件 PDF 分支现调用新增的 `creative_hub/ui/creative_pdf_reader.dart`。原 iframe 路径在实际内嵌浏览器中出现空白后，改用已安装的 `pdfrx`（2.4.7）及其 PDFium 引擎，不新增依赖。源码沿用浅灰阅读底色，关闭页面投影，使用 `AppLoadingIndicator`、`AppButton`、`AppIconButton` 与 `AppText.number`；提供页码、前后页边界禁用及加载失败重试。最终两个横屏尺寸及实际内嵌浏览器已确认正文与翻页，证据见验收记录。
- 交互状态继续遵循 `data/ → state/ → ui/`。收藏、发布、演示订单和阅读进度有对应仓库及控制器，界面保留局部的视图选择状态。

## 局部差异与既有文档漂移

前次扫描指出的小课件卡片与集市详情使用中性科目标签，现已在 `learning_topics_page.dart` 的 `_card` 与 `marketplace_page.dart` 的 `_detail` 改为 `AppTag.subject(...)`，该项代码差异已修复。

以下差异仍按现状记录，交接过程未修改相关代码，也不把这些差异转写为全局设计规则：

1. 网格卡片使用固定主轴尺寸：专题 322、集市 334；集市网格间距为 18。页面另有直接书写的间距和圆角。多数值与既有视觉尺度相近，但固定卡高、18 间距及字面量不等同于规范中“不固定内容卡高度、间距来自令牌”的通用要求。它们应按实际内容和两个目标横屏尺寸核验，不能据此宣称完成全量令牌迁移。
2. 既有 `docs/设计规范.md` 的弹窗说明仍写旧的 `showConfirmDialog` / `showInfoDialog` 只能在外壳内使用；当前 `AGENTS.md` 明确说明旧弹窗在外壳外回退为 identity。此处是已存在的文档口径差异，本次保持原文件，不借功能扩展改写规范。新集市确认仍使用 `showAppConfirm`。
