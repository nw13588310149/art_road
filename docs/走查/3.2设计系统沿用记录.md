## 页面组织与交互状态

### 校长驾驶舱

`lib/features/teaching_overview/ui/principal_overview.dart` 取消顶部主副标题，只保留校区、日期和查看作品。上下两行共用 65:35 分栏与 16 间距：教学概览/今日待办，近期作品/教学跟进。三项指标放在趋势卡内；底部为六项入口，包含“更多管理”，由其承接次级管理操作。近期作品、姓名和计数取业务数据，不固定为批准图中的示例。

本页在内容宽度 740 处切换成纵向组合，工具行小于 680 时换行。1180×820 与 1024×768 的已查看截图均保留双栏与底部入口。它们是本页的布局阈值；[3.1 沿用记录](3.1设计系统沿用记录.md) 所述 7:4 是此前页面组织的历史记录，不再描述当前首页。

### 随页专业工具栏

`floating_toolbox_host.dart` 将业务页面、工具工作台与参数显示分开：默认收起；展开为 52px 单列，左右停靠；取色和测量进入精确操作时收起工具列。收起参数保留当前效果，结束工具清除效果，路由变化清理页面效果；笔记编辑、完整工具箱与业务模态界面隐藏外层入口。完整工具箱仍保留当前原图会话。

参数和撤销由 `state/page_tools_controller.dart` 管理。计时收起参数后继续，离开页面或进入工作台暂停；测量结果标明页面逻辑像素与相对比例，不能理解为实物尺寸。取色读取业务画面，工具列和参数面板不作为采样内容。网格参数的 Slider 使用局部 Overlay 约束 Web 语义层，该处理沿用笔记滑杆已有方式。

本节文件均位于 `lib/features/art_toolbox/`。52 / 44 的尺寸用于这一浮动专业工具列，不改写组件库普通图标按钮 40 / 34 的既有尺寸。

### 短板、练习和教学跟进

`lib/core/demo/data/demo_artwork_data.dart` 的 `_subjectInsights` 以科目划分样本，按最近点评时间选择最多十份带分项点评的作品；同作品有效任课分项先求多师均值，再对作品等权统计。界面显示 5 级尺度、作品与点评数量、日期区间、原作和教师依据，组长与校长评分不混入任课分项。缺失值保持缺失，不渲染为零。

首页短板与成长页继续使用现有文字、标签和图表；练习安排连接知识点资料和提交，来源由 `practiceSource` 保留。教师和校长名单在 `teaching_student_list.dart` 复用搜索、选择、状态胶囊及跟进抽屉；“已记录处理”说明协作处理进度，不自动清除作品风险或改变分数。仓库与控制器仍位于对应 `data/`、`state/`，记录通过演示接口写入 DemoStore。

收尾复核提出两项信息表达问题：组长首页未来课程缺少明确日期，教师学生档案分项缺尺度、样本与区间。当前代码分别在 `home_dashboard_state.dart` / `home_page.dart` 增加“今日暂无排课”和“下一次课程 · 实际日期”，在 `teaching_overview_page.dart` 的 `_studentDimensions` 增加 5 级、作品/点评数、时间和聚合规则。已查看两种尺寸的新截图，日期、分项尺度、样本和统计说明均可见；独立复核确认这两项 P2 已解决，结论仅覆盖修复范围，不扩大为所有页面的独立设计审查。

### 作品集市

`lib/features/creative_hub/ui/marketplace_page.dart` 保持图片主导的发现网格；数字授权、实物作品和创作分享可按类型筛选。详情以大图和阅读型信息双栏呈现，明确作者、科目、许可或实体规格。新建采用整页表单；订单、创作者工作台、平台管理按任务分开，未把所有页面统一为驾驶舱式卡片。

`marketplace_editor.dart`、`market_forms.dart`、`market_order_page.dart` 与 `market_management.dart` 沿用组件库字段、抽屉、确认和状态标签。数字交付与许可、实物地址及物流、售后与平台处理都有各自可见状态。订单保留成交时作品、价格与条款快照；支付和退款显示演示性质，不表示已接入真实商户。数据与状态分别位于 `creative_hub/data/`、`creative_hub/state/`，演示接口由 `lib/core/demo/fixtures/marketplace_fixtures.dart` 承接。

集市网格当前在内容宽度 880 处切换三列/两列，固定卡高为 348、横向间距为 18。这些是观察到的页面值，不提升为设计令牌；3.1 记录中的集市卡高 334 已不适用于本版。
