# 3.1 教学、阅读与集市验收

日期：2026-11-15。以 Flutter Web 横屏演示版为范围；基础版本 `ec6e271`，参考工作树 `80e9dd3c` 只读。

## 产品结果

- 校长：统一驾驶舱与报表页头，FL Chart 折线与校区柱状图；指标、点击下钻与列表数据来自同一教学仓库。
- 作品：用户可见文案统一；支持多个指定老师独立评价、同人编辑历史、全部老师完成后交给组长、校长独立评分；每位老师待办按自己的完成状态统计。
- 小课件：8 个知识专题，PDF / 图片书籍组合，选择或上传、校验、发布、收藏与阅读。
- 集市：8 个示例作品，展示 / 使用许可、原创声明、发布与撤下、幂等模拟购买、订单许可快照、数字作品阅读。

## 验证证据

- `dart analyze lib test` 与根目录 `dart analyze`：均无问题；后者日志 `build/qa/v31-shipping-analyze.log`。
- `flutter test --no-pub`：487 项通过，日志 `build/qa/v31-shipping-tests.log`。新增测试覆盖多人评分与历史、组长等待完整老师阶段、无演示账号的共同点评者按时补全、资料关联与权限、按读者隔离的图片书进度、订单隔离 / 幂等 / 下架快照、金额与声明校验，以及两种内容宽度的表单校验与布局。
- 1180×820 与 1024×768 全身份首轮：各 73 个场景，71 通过，2 个阅读断言失败，页面脚本异常 0。原始报告保留在 `build/qa/v31-final-1180/report.json` 与 `build/qa/v31-final-1024/report.json`。
- 两个阅读失败来自脚本：PDF 行按钮名称包含类型副标题，原脚本错误地使用完整匹配；图片书阅读页显示书刊正式标题，旧断言使用资源别名。已统一种子书名与正式书名、修正石膏书页数并更新断言，复测见最终证据。
- 首版小课件卡片曾溢出 2px，已修正并以控件测试验证。校长页面两个尺寸专项各 6 个场景通过。
- PDF 用现有图片书页制作，3 份合计 32 页；已用 Poppler 渲染检查内页。复现脚本 `tool/ebooks/make_topic_pdfs.py`，不新增依赖。
- 实际内嵌浏览器检查发现：原 iframe 即使成功取得有效 PDF，也可能不显示正文。因此新增阅读器使用项目已有 pdfrx 及随包 PDFium，提供页码、翻页、加载和失败重试；QA 改为断言实际解析页数与翻页结果，不再以 iframe 存在和文件头有效代替阅读验收。
- 静态设计检测不支持 Dart：design-taste lint 明确无适用文件，impeccable detect 返回空列表。浏览器 inspector 已运行；CanvasKit 的视觉检查以实际页面截图和控件布局测试为准，不将空 DOM 检测视为合格证明。

## 交付边界

本版沿用本地演示后端，交易不扣真实款项。Web 新上传的 Blob 文件不跨刷新持久化，内置资料可重复阅读。支付、权属审核、退款及受控交付需正式服务接入，见后端缺口清单。没有原生 iOS / Android 编译环境，本轮未将网页结果替代原生验收。
