# 集市商业闭环与接口契约

## 交付范围

当前版本为本地演示后端，可走通数字授权和实物作品交易。所有金额使用整数分，不收取真实款项。每单一件作品，实物库存支持多件；不引入未经确认的平台手续费。公开作品图片用于预览，数字文件只从已付款订单的交付入口获取。

发现页提供类型、科目、收藏、关键词与价格排序。详情呈现作者、作品说明、售价、数字许可范围或实物规格/品相、库存、运费、发货时限，以及购买者评价。分享链接带 listingId，可直接打开对应作品。创作者工作台统一管理发布和卖出订单，管理员及校长拥有审核入口。

## 发布与交易状态

发布：草稿 → 提交审核 → 通过后上架；退回可修改再审。审核中可撤回，上架后需下架再编辑。归档保留历史订单，禁止客户端绕过作者权限修改。

订单：待付款 → 模拟支付。数字订单直接完成并交付；实物进入待发货 → 卖家填写承运方/单号 → 待收货 → 买家确认完成。订单创建时保存不可变的作品、价格、条款、文件与收货地址快照。修改原发布或地址簿不改变已有订单。

待付款订单保留 30 分钟。实物下单即预留一件库存；取消或超时仅归还一次。支付、取消、退款具有状态保护；创建订单使用买家级幂等键。金额变化要求重新核对，禁止超卖、购买本人作品、获取他人订单或未付款文件。页面在待付款期间定时刷新过期状态，服务端在订单读写入口再次判断。

售后：买家申请 → 卖家处理。数字或未发货实物同意后模拟退款；已寄出的实物需要退货地址 → 买家填写寄回物流 → 卖家签收后退款并下架作品待检查。拒绝申请需填写理由，买家可以申请平台介入。平台支持申请时执行退款或下架；记录操作人、理由和时间。退款后交付入口失效。作品评价仅允许已完成订单提交一次。

平台介入后，买家订单显示「平台处理中」；处理完毕后，无论是否支持申请，均展示处理说明与时间，并写入订单事件。处理中不得重开售后覆盖原申请，同一申请不能重复升级。举报处理导致下架时，作者可在作品记录看到处理依据。

## API

全部路径以 `/app/market` 开头，由 `MarketRepository` 调用，`MarketController` 协调状态，`marketplace_fixtures.dart` 提供对应演示响应。

|对象|接口|
|---|---|
|作品|GET `/listings`、GET `/listings/{id}`、POST `/listings`、POST `/listings/{id}/save`|
|发布操作|POST `/listings/{id}/submit`、`withdraw`、`remove`、`favorite`、`report`|
|地址|GET/POST `/addresses`、POST `/addresses/{id}/remove`|
|订单|GET/POST `/orders`、GET `/orders/{id}`|
|履约|POST `/orders/{id}/pay`、`cancel`、`ship`、`receive`、`review`|
|数字交付|GET `/orders/{id}/delivery`；返回文件类型/URL及许可凭证信息|
|售后|POST `/orders/{id}/refund`、`refund-decision`、`return`、`return-received`、`dispute`|
|审核|GET `/moderation`、POST `/listings/{id}/moderate`、POST `/cases/{id}/resolve`|

下单字段：listingId、idempotencyKey、expectedPriceCents、expectedTotalCents、termsAccepted；实物另传 addressId。订单状态采用 pending_payment、awaiting_shipment、shipped、completed、cancelled、expired、refund_requested、return_required、return_shipped、refunded。失败返回统一业务错误，表单保留输入。

交付下载前重新读取权限；PDF 类型使用资源元数据，不能根据无扩展名的 blob URL 猜测。许可凭证可保存为文本，文件可保存或预览。地址簿支持新增、编辑、删除和默认地址。

## 上线接入边界

正式上线仍需要服务端事务库存与数据库唯一约束、支付订单及签名回调/对账/退款、实名认证和未成年人交易规则、权属审核与争议工单、物流查询、合同条款审查、商户结算与隐私保障。本地审核身份仅用于演示，不能替代生产平台权限体系。

演示资产打包在客户端，不能提供真实数字版权保护；生产文件必须使用鉴权存储与短时下载链接。Web 上传暂存为 blob，刷新后失效；生产应接入持久存储、上传恢复和文件安全检查。演示物流展示填写的承运方及单号，没有伪造物流轨迹。原生 iPad 的文件保存和分享仍需真机验收。
