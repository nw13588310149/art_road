# 美育集 3.1：教学、阅读与创作流通

## 产品主线

学生在小课件中围绕知识点学习，在作品中提交练习并获得多位老师、教学组长和校长的反馈；作品经本人选择，可以独立发布到集市展示或出售数字使用许可。校长通过教学总览掌握进度，进入具体作品和学生解决问题。

本版继续采用本地演示后端，所有修改进入 DemoStore，业务记录支持刷新保留和重置。Web 新上传的文件使用 Blob 地址，只在当前浏览器文档内有效；示例书籍与 PDF 可持续阅读。集市结算是明确标记的模拟交易，不收取真实款项。

## 作品：三个身份，多人独立评价

- 统一将用户界面的“作业”命名为“作品”；教学任务称为“作品任务”，学生提交称为“提交作品”。保留旧 API 和路由兼容。
- 点评身份只有任课老师、教学组长、校长三类。一个作品可有多位任课老师各自独立的评分、评语、批注、语音与时间；同一老师修改自己的评价，保留历史。
- 全部指定的任课老师完成评价后进入本科教学组长的点评队列；组长能够独立评分和写评语。原来的抽查原因与点评质量信息仍保留作内部教学管理使用。
- 校长可直接查看全链条，并可填写独立分数及评语。校长评分不覆盖老师或组长的评分。
- 作品详情按三个身份分组显示；评分标明来源。学习统计采用明确的“教学参考分”：组长有评分时取组长分，否则取已评分任课老师的标准化平均分；校长分独立展示，不混入该统计。
- 修改作品产生新版本，旧版本及点评继续保留。未点评不显示为零分。

## 校长端：从概览进入行动

首屏回答“今天哪些教学环节需要关注”：校区筛选与日期、关键教学指标、近七天趋势、待处理事项、近期作品。次级页面承接老师履职、校区与班级对比、学生关注名单及作品点评链。

视觉沿用现有外壳和组件库。页面取消占据大量宽度的个人资料栏，采用统一对齐的数字、低对比度分隔、作品缩略图和有单位的图表。图表使用 FL Chart 1.3.1，禁用入场与切换动画，提供读屏摘要、刻度和触摸提示。小尺寸横屏保持相同信息顺序。

## 小课件：短时阅读的知识专题

- 区别于校园文件目录：每份小课件围绕一个具体知识点，如石膏头像的明暗交界线、静物色彩的冷暖关系、人物动态的重心。
- 一个专题包含多份资料，资料类型为 PDF 或图片书籍；展示资料数量、科目、难度、建议阅读时长、作者及知识点。
- 列表支持科目、搜索和收藏；详情先讲学习目标，再列阅读资料与练习建议。复用书刊阅读器，保持翻页与阅读进度。
- 新增页使用完整页面：填写标题、简介、科目、知识点、时长；从示例资料中选择或上传 PDF/多张图片，预览资料与封面，校验后发布。所有身份可分享自己的阅读专题。

## 集市：展示与数字许可购买

- 所有身份均可浏览、收藏与发布。作品展示与付费许可清晰区分；展示作品不出现购买按钮。
- 列表包含真实美术图片、标题、作者、科目、售价/仅展示；支持搜索、科目筛选、收藏、我的发布与订单。
- 详情显示大图、创作说明和许可范围。第一版提供“个人学习使用”与“教学展示使用”两种非独占数字许可；不表示著作权转让。交易页面不提供法律保证。
- 新增页支持从本人作品档案选择或上传图片，填写创作说明、展示/出售、价格与许可方式，确认拥有发布权限后发布。
- 结算前展示作品、许可、金额与演示交易说明；用户确认后生成对应订单，重复点击/重复购买不重复扣单。本人发布不可购买。订单展示所购许可及数字作品。
- 未成年人真实支付、实名认证、退款、争议处理、侵权举报与内容审核属于上线服务需求，记录到后端缺口，不在演示中伪造已接入能力。

## 验收

多老师评价互不覆盖；组长与校长评分独立；教学统计、任务和作品列表一致。小课件新增后可查找、打开资料与收藏；集市发布后可浏览、模拟购买和在订单中查阅。分析零问题，Flutter 测试通过，1180×820 与 1024×768 校验页面和交互结果。

## 实现边界与内容口径

既有校园课件继续承载学校文件分发，小课件单独承载知识专题，不替换原来的校园资料路由。集市交易对象为一份数字作品的非独占使用许可，作品归属与教学评分不随购买改变。

本轮仅依赖 FL Chart 1.3.1（MIT，已获一次下载许可）。新增数据模型、仓库、StateNotifier 与页面在 creative_hub 中分层；接口全部有本地演示响应。原有参考页面控件与外壳保持一致。集市中的售价用于用户明确要求的购买体验，是演示作品金额，不是平台产品报价；因此不套用宣传物料规则中的“不得报价”，其他宣传禁词继续检查。
